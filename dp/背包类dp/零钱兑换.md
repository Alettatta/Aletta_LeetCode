# Problem Description
给你一个整数数组 coins，表示不同面额的硬币；以及一个整数 amount，表示总金额。

计算并返回可以凑成总金额所需的最少的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 -1。

你可以认为每种硬币的数量是无限的。


# Solution
完全可以用一维 dp 解决：dp[j] 表示凑成金额 j 的最少硬币数。

base case: dp[0] = 0

状态转移方程：dp[j] = min(dp[j], dp[j-coin] + 1)

如果使用二维：定义 dp[i][j] 表示使用前 i 个硬币类型（coins[0..i-1]）凑成金额 j 的最少硬币数。
```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        n = len(coins)
        # dp[i][j]: 用前 i 种硬币凑成金额 j 的最少硬币数
        dp = [[float('inf')] * (amount + 1) for _ in range(n + 1)]
        
        # base case: 凑成金额 0 需要 0 个硬币
        for i in range(n + 1):
            dp[i][0] = 0
        
        # 状态转移
        for i in range(1, n + 1):
            for j in range(1, amount + 1):
                coin = coins[i-1]
                if j >= coin:
                    # 用第 i 种硬币 或 不用
                    dp[i][j] = min(dp[i-1][j], dp[i][j-coin] + 1)
                else:
                    dp[i][j] = dp[i-1][j]
        
        return dp[n][amount] if dp[n][amount] != float('inf') else -1
```


# Code

## LC version

```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        dp = [float('inf')] * (amount + 1)
        
        dp[0] = 0

        for coin in coins: # 每个硬币可以无限使用
            for j in range(coin, amount + 1):
                dp[j] = min(dp[j], dp[j - coin] + 1)

        return dp[amount] if dp[amount] != float('inf') else -1
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        dp = [float('inf')] * (amount + 1)
        
        dp[0] = 0

        for coin in coins: # 每个硬币可以无限使用
            for j in range(coin, amount + 1):
                dp[j] = min(dp[j], dp[j - coin] + 1)

        return dp[amount] if dp[amount] != float('inf') else -1

for line in sys.stdin:
    n, amount = map(int, line.split())
    coins = list(map(int, sys.stdin.readline().split()))
    result = Solution().coinChange(coins, amount)
    print(result)
```
