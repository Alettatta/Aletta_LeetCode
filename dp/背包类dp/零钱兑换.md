# Problem Description
给你一个整数数组 coins，表示不同面额的硬币；以及一个整数 amount，表示总金额。

计算并返回可以凑成总金额所需的最少的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 -1。

你可以认为每种硬币的数量是无限的。



# Code

## LC version

```python
# dp[i] = 凑出amount==i的时候使用coins中最少的硬币个数（coins中可以重复使用）
# 对每个金额 i，考虑"最后一枚硬币用哪个"：dp[i] = min(dp[i], dp[i - coin] + 1)——对所有 coin ≤ i 

class Solution:
    def coinChange(self, coins, amount):
        dp = [float('inf')] * (amount + 1)
        dp[0] = 0
        for i in range(1, amount + 1): # 从金额=1开始凑，一直凑到amount
            for coin in coins: # 每个amount可以从coin中找解决方案
                dp[i] = min(dp[i], dp[i - coin] + 1)
        return dp[amount] if dp[amount] != float('inf') else -1
```



# Complexity Analysis
- 时间复杂度：O(mn)
- 空间复杂度：O(mn)
