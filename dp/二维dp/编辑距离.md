# Problem Description

给你两个单词 word1 和 word2，请返回将 word1 转换成 word2 所使用的最少操作数。

你可以对一个单词进行如下三种操作：插入一个字符、删除一个字符、替换一个字符


# Solution
## 原理
编辑距离问题就是给我们两个字符串 s1 和 s2，只能用三种操作，让我们把 s1 变成 s2，求最少的操作数。需要明确的是，不管是把 s1 变成 s2 还是反过来，结果都是一样的，所以后文就以 s1 变成 s2 举例。

解决两个字符串的动态规划问题，一般都是用两个指针 i, j 分别指向两个字符串的头部或尾部，然后尝试写状态转移方程。比方说让 i, j 分别指向两个字符串的尾部，把 dp[i], dp[j] 定义为 s1[0..i], s2[0..j] 子串的编辑距离，那么 i, j 一步步往前移动的过程，就是问题规模（子串长度）逐步减小的过程。

![编辑距离](./photos/edit.gif)

```python
s1 = rad, s2 = apple，过程模拟如下：
初始比较：s1[2]='d'，s2[4]='e'

第1步：插入 'e'（因为 s2 尾部有 'e'，s1 没有）
s1: r a d e  (插入 e)
s2: a p p l e
现在尾部 'e' 匹配了，移动指针：s1 剩余："rad"；s2 剩余："appl"

第2步：插入 'l'
s1: r a d l e  (插入 l)
s2: a p p l e
尾部 'l' 匹配，移动指针：s1 剩余："rad"；s2 剩余："app"

第3步：替换 'd' → 'p'
s1: r a p l e  (d→p)
s2: a p p l e
尾部 'p' 匹配，移动指针：s1 剩余："ra"；s2 剩余："ap"

第4步：替换 'a' → 'p'
s1: r p p l e  (a→p)
s2: a p p l e
尾部 'p' 匹配，移动指针：s1 剩余："r"；s2 剩余："a"

第5步：替换 'r' → 'a'
s1: a p p l e  (r→a)
s2: a p p l e

操作数：5 次（3 次替换 + 2 次插入）
```

## 暴力算法
base case 是 i 走完 s1 或 j 走完 s2，可以直接返回另一个字符串剩下的长度。对于每对字符 s1[i] 和 s2[j]，可以有四种操作：

```python
if s1[i] == s2[j]:
    啥都别做（skip）
    i, j 同时向前移动
else:
    三选一：
        插入（insert）
        删除（delete）
        替换（replace）
```

暴力递归算法如下：

```python
class Solution:
    def minDistance(self, s1: str, s2: str) -> int:
        m = len(s1)
        n = len(s2)
        return self.dp(s1, m - 1, s2, n - 1) # i，j 初始化指向最后一个索引

    # 定义：返回 s1[0..i] 和 s2[0..j] 的最小编辑距离
    def dp(self, s1: str, i: int, s2: str, j: int) -> int:
        # base case
        if i == -1:
            return j + 1
        if j == -1:
            return i + 1

        if s1[i] == s2[j]:
            # 啥都不做
            return self.dp(s1, i - 1, s2, j - 1)

        return min(
            # 插入
            self.dp(s1, i, s2, j - 1) + 1,
            # 删除
            self.dp(s1, i - 1, s2, j) + 1,
            # 替换
            self.dp(s1, i - 1, s2, j - 1) + 1
        )
```

skip: 本来就相等，不需要任何操作，s1[0..i] 和 s2[0..j] 的最小编辑距离等于 s1[0..i-1] 和 s2[0..j-1] 的最小编辑距离；也就是说 dp(i, j) 等于 dp(i-1, j-1)

插入 dp(s1, i, s2, j - 1) + 1：我直接在 s1[i] 后面插入一个和 s2[j] 一样的字符；那么 s2[j] 就被匹配了，前移 j，继续跟 i 对比；别忘了操作数加一

删除 (s1, i - 1, s2, j) + 1：我直接把 s[i] 这个字符删掉，那么 s1[0..i-1] 和 s2[0..j] 的最小编辑距离就等于 前移 i，继续跟 j 对比，操作数加一

替换 dp(s1, i - 1, s2, j - 1) + 1：我直接把 s1[i] 替换成 s2[j]，这样它俩就匹配了，同时前移 i，j 继续对比，操作数加一

对于子问题 dp(i-1, j-1)，如何通过原问题 dp(i, j) 得到呢？有不止一条路径，比如 dp(i, j) -> #1 和 dp(i, j) -> #2 -> #3。一旦发现一条重复路径，就说明存在巨量重复路径，也就是重叠子问题。————需要 dp 算法优化

## dp 优化
我们需要定义一个 dp 数组，然后在这个数组上执行状态转移方程。首先明确 dp 数组的含义，由于本题有两个状态（索引 i 和 j），所以dp 数组是一个二维数组，大概长这样：

![编辑距离](./photos/edit.jpg)

dp[i+1][j+1]（dp[i], dp[j] 定义为 s1[0..i], s2[0..j] 子串的编辑距离，因为可以相互转化所以是二维数组）：s1[0..i] 和 s2[0..j] 的最小编辑距离（dp 函数的 base case 是 i, j 等于 -1，而数组索引至少是 0，所以 dp 数组会偏移一位）

# Code

## LC version

```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)] # 得到 m*n 矩阵

        # base case：如果有一方为空
        for i in range(1, m + 1):
            dp[i][0] = i
        for j in range(1, n + 1):
            dp[0][j] = j

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]: # skip
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = min(
                        dp[i - 1][j] + 1, # delete: i动
                        dp[i][j - 1] + 1, # insert: j动
                        dp[i - 1][j - 1] + 1 # replace: 两者都动
                    )

        return dp[m][n]
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys


class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)] # 得到 m*n 矩阵

        # base case：如果有一方为空
        for i in range(1, m + 1):
            dp[i][0] = i
        for j in range(1, n + 1):
            dp[0][j] = j

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]: # skip
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = min(
                        dp[i - 1][j] + 1, # delete: i动
                        dp[i][j - 1] + 1, # insert: j动
                        dp[i - 1][j - 1] + 1 # replace: 两者都动
                    )

        return dp[m][n]


lines = []
for line in sys.stdin:
    lines.append(line.strip())

i = 0
while i + 1 < len(lines):
    word1 = lines[i]
    word2 = lines[i + 1]
    result = Solution().minDistance(word1, word2)
    print(result)
    i += 2
```
