# Problem Description
一个机器人位于一个 m x n 网格的左上角（起始点位置 grid[0][0]）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（终点位置 grid[m - 1][n - 1]）。

问总共有多少条不同的路径？



# Solution

dp[i][j]: 从grid[0][0]移动过来的路径数量

base case：dp[0][…] = dp[…][0] = 1，第一行第一列上任意位置抵达的方式只有1种

dp[i][j] = dp[i][j - 1] + dp[i - 1][j]，注意只有两种抵达的方式，不能从左上角斜着过去


# Code

## LC version

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # dp[i][j]: 从grid[0][0]移动过来的路径数量
        # dp[i][j] = dp[i][j - 1] + dp[i - 1][j]
        
        dp = [[0] * n for _ in range(m)]

        # base case: dp[0][…] = dp[…][0] = 1，第一行第一列上任意位置抵达的方式只有1种
        for i in range(m):
            dp[i][0] = 1
        for j in range(n):
            dp[0][j] = 1

        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = dp[i][j - 1] + dp[i - 1][j]
                
        return dp[m - 1][n - 1]
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys


class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        # dp[i][j]: 从grid[0][0]移动过来的路径数量
        # dp[i][j] = dp[i][j - 1] + dp[i - 1][j]
        
        dp = [[0] * n for _ in range(m)]

        # base case: dp[0][…] = dp[…][0] = 1，第一行第一列上任意位置抵达的方式只有1种
        for i in range(m):
            dp[i][0] = 1
        for j in range(n):
            dp[0][j] = 1

        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = dp[i][j - 1] + dp[i - 1][j]
                
        return dp[m - 1][n - 1]


for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    parts = line.split()
    if len(parts) < 2:
        continue
    m = int(parts[0])
    n = int(parts[1])
    result = Solution().uniquePaths(m, n)
    print(result)
```

- 时间复杂度：O(mn)
