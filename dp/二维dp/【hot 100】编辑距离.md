# Problem Description

给你两个单词 word1 和 word2，请返回将 word1 转换成 word2 所使用的最少操作数。

你可以对一个单词进行如下三种操作：插入一个字符、删除一个字符、替换一个字符


# Solution
dp[i][j] = word1前i个字符word1[0..i-1]转换为word2前j个字符word2[0..j-1]最少需要多少个操作

```python
dp[i][j] 的转移，不是"假设前面已配对，只处理末尾"，而是：看两个串的末尾字符 a、b。根据 a、b 是否相等，决定"缩小问题"的方式。

1. 当 a == b（末尾相等）
末尾这个字符不用任何操作就匹配了，所以可以免费把它从两边都去掉，问题缩小到 dp[i-1][j-1]：dp[i][j] = dp[i-1][j-1]

2. 当 a != b（末尾不等）
末尾这个字符必须通过某种操作处理，有三种选择，每种选择会让问题以不同方式缩小：
（1）删 a：a 没了，word1 缩到 i-1，word2 不动 → dp[i-1][j] + 1
（2）插 b：word2 的 b 被匹配掉，word2 缩到 j-1，word1 不动 → dp[i][j-1] + 1
（3）换 a→b：a 变成 b，两边末尾都匹配、都缩 → dp[i-1][j-1] + 1
```

# Code

## LC version

```python
class Solution:
    def minDistance(self, word1, word2):
        m = len(word1)
        n = len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # base case: dp[i][0], dp[0][j]，光删/加就行
        for i in range(0, m + 1):
            dp[i][0] = i
        for j in range(0, n + 1):
            dp[0][j] = j

        # DP方程
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = 1 + min(dp[i - 1][j], # 删除
                                       dp[i][j - 1], # 插入
                                       dp[i - 1][j - 1]) # 替换

        return dp[m][n]
```

# Complexity Analysis
- 时间复杂度：O(mn)
- 空间复杂度：O(mn)
