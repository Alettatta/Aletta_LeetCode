# Problem Description
给你一个整数数组 nums，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案保证可以用 32 位 整数存储。



# Solution
dp[i]=以nums[i]结尾的连续子数组最大乘积；dp[i] = max(nums[i], dp[i-1]*nums[i]) -> 这在乘积问题里面不对，因为遇到负数的话最小最大发生改变

**因此需要维护一大一小两个数组： 因为负数×负数=正数，minP[i-1]（可能是很负的数）乘上 nums[i]（负数）后会翻盘成最大**
```python
maxP[i] = 以 nums[i] 结尾的连续子数组的最大乘积
minP[i] = 以 nums[i] 结尾的连续子数组的最小乘积
```
        
# Code

## LC version

```python
class Solution:
    def maxProduct(self, nums):
        if not nums:
            return 0
        n = len(nums)
        maxP = [0] * n
        maxP[0] = nums[0]
        minP = [0] * n
        minP[0] = nums[0]

        for i in range(1, n):
            a = maxP[i - 1] * nums[i]
            b = minP[i - 1] * nums[i]
            maxP[i] = max(nums[i], a, b)
            minP[i] = min(nums[i], a, b)
            
        return max(maxP)
```

# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
