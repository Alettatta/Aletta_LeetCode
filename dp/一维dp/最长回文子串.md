# Problem Description

给你一个字符串 s，找到 s 中最长的回文子串。


# Solution
注意是找到，区别于“分割回文子串”，分割才是找子集——回溯问题。

这里需要找最值，可以用dp。

dp数组含义：dp[i]表示以s[i]为中心的最长回文子串

判断回文串使用双指针l和r，而不用sort
        

# Code

## LC version

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:     
        ans = ''
        for i in range(len(s)):
            s1 = self.palindrome(s, i, i) # 奇数回文长度，例如b，有一个中心i
            s2 = self.palindrome(s, i, i + 1) # 偶数回文长度例如abba，有两个中心i、i+1
            # ans = longest(ans, s1, s2)
            ans = ans if len(ans) > len(s1) else s1
            ans = ans if len(ans) > len(s2) else s2
        return ans

    def palindrome(self, s, l, r):
        # 从中间往两边展开
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1
            r += 1 # dabac
        return s[l + 1: r] # 此时s[l+1…r-1]是最长回文串
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys

class Solution:
    def longestPalindrome(self, s: str) -> str:
        # dp数组含义：dp[i]表示以s[i]为中心的最长回文子串
        # 判断回文串使用双指针l和r，而不用sort
        
        ans = ''
        for i in range(len(s)):
            s1 = self.palindrome(s, i, i) # 奇数回文长度，例如b，有一个中心i
            s2 = self.palindrome(s, i, i + 1) # 偶数回文长度例如abba，有两个中心i、i+1
            # ans = longest(ans, s1, s2)
            ans = ans if len(ans) > len(s1) else s1
            ans = ans if len(ans) > len(s2) else s2
        return ans

    def palindrome(self, s, l, r):
        # 从中间往两边展开
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1
            r += 1 # dabac
        return s[l + 1: r] # 此时s[l+1…r-1]是最长回文串

for line in sys.stdin:
    # 不使用 strip()，保留可能为空的字符串；只去掉行尾换行符
    s = line.rstrip('\n').rstrip('\r')
    result = Solution().longestPalindrome(s)
    print(result)
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
