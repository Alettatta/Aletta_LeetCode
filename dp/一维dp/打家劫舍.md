# Problem Description

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

给定一个代表每个房屋存放金额的非负整数数组，计算你不触动警报装置的情况下，一夜之内能够偷窃到的最高金额。


# Solution
dp[i]: 前 i 个房屋能偷到的最大金额 -> 一共n个房子，所以dp数组长度为n+1 -> dp[0] = 0, dp[1] = nums[0]

状态转移方程：dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])——只看每一步的决策，抢or不抢（注意抢的话，第i个房屋的nums下标是i-1）


# Code

## LC version

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        if n == 1:
            return nums[0]

        dp = [0] * (n+1)
        dp[0] = 0
        dp[1] = nums[0]
        
        for i in range(2, n + 1):
            dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])
        
        return dp[n]
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        if n == 1:
            return nums[0]

        dp = [0] * (n+1)
        dp[0] = 0
        dp[1] = nums[0]
        
        for i in range(2, n + 1):
            dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])
        
        return dp[n]


pending_n = None
for line in sys.stdin:
    parts = line.strip().split()
    if not parts:
        continue
    if pending_n is None:
        pending_n = int(parts[0])
        if pending_n == 0:
            result = Solution().rob([])
            print(result)
            pending_n = None
        continue
    nums = list(map(int, parts))
    result = Solution().rob(nums)
    print(result)
    pending_n = None
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
