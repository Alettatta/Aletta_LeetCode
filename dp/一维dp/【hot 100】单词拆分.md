# Problem Description

给你一个字符串 s 和一个字符串列表 wordDict 作为字典。请你判断是否可以利用字典中出现的单词拼接出 s。

注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。


# Solution

dp[i] = 字符串s的前缀i个字符（即s[0..i-1]）能否被字典拼出

拆分问题在于能否找到j使得s[0..j-1]能拼出，且s[j..i-1]正好是字典里的一个词

dp[i] = True——当且仅当存在 j (0 ≤ j < i)，使得：dp[j] == True 且 s[j..i-1] 在字典中

# Code

## ACM version

```python
import sys 

class Solution:
    def wordBreak(self, s, wordDict):
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True
        wordSet = set(wordDict)

        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] and s[j : i] in wordSet:
                    dp[i] = True
                    break 

        return dp[n]


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    s = data[idx]; idx += 1
    N = int(data[idx]); idx += 1
    wordDict = []
    for _ in range(N):
        wordDict.append(data[idx])
        idx += 1
    ans = Solution().wordBreak(s, wordDict)
    print('true') if ans == True else print('false')
```

集合加速查找的原因：列表是 O(n)；集合底层是哈希表 O(1)


# Complexity Analysis
- 时间复杂度：O(n^2)
- 空间复杂度：O(n)
