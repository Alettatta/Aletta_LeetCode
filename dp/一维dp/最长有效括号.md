# Problem Description

给你一个只包含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号子串的长度。


# Solution
dp[i]=以s[i]结尾的最长括号子串的长度

如果 s[i] == '('：不可能以 '(' 结尾形成有效括号，dp[i] = 0

如果 s[i] == ')'：才可能形成有效括号，需要往前找配对的 '('

① s[i-1] == '(',dp[i] = dp[i - 2] + 2

② s[i-1] == ')'，形成'...(...))——dp[i-1] 是"以 i-1 结尾的有效括号长度"，说明 s[i-1-dp[i-1]+1 .. i-1] 是一段有效括号。那么 s[i] 要配对的那个 '('，就在这段有效括号的前一个位置


# Code

## LC version

```python
class Solution:
    def longestValidParentheses(self, s):
        if not s:
            return 0
        n = len(s)
        dp = [0] * n

        for i in range(1, n):
            if s[i] == ')':
                if s[i - 1] == "(":
                    dp[i] = dp[i - 2] + 2
                else:
                    match = i - 1 - dp[i-1] # 配对的位置
                    if match >= 0 and s[match] == '(':
                        dp[i] = (dp[i-1] + 2) + (dp[match-1] if match >= 1 else 0)
        return max(dp)
```

# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
