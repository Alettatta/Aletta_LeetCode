# Problem Description

给你一个只包含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号子串的长度。


# Solution

dp[i]:以 s[i] 结尾的最长有效子串的长度

如果 s[i] == "("，以它结尾的子串不可能是有效的，所以 dp[i] = 0

如果 s[i] == ")"，才可能形成有效括号串，此时需要分两种情况讨论：

1. s[i-1] == '('，形如 ...()，此时 s[i-1] 和 s[i] 配对，dp[i] = dp[i-2] + 2
2. s[i-1] == ')'，形如 ...))，此时我们需要找到与 s[i] 配对的 ( 位置。设 prev = i - dp[i-1] - 1，即当前有效串 s[i-dp[i-1] ... i-1] 的前一个字符位置。如果 prev >= 0 且 s[prev] == '('，则 prev 与 s[i]（")"） 配对，中间包裹了 dp[i-1] 长度的有效串。此时：dp[i] = dp[i-1] + 2 + dp[prev-1]   （若 prev-1 >= 0，否则不加），其中 dp[prev-1] 表示配对的 ( 前面可能存在的连续有效串；2 表示既要考虑 s[i] 也要考虑 s[prev]。
```python
# 注意两个递推式子的 i-1、i-2区分
...  (  [ 有效串 ]  )   ← 这是 s[i]
      ↑             ↑
     prev           i
```

# Code

## LC version

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        if n < 2:
            return 0

        dp = [0] * n
        ans = 0

        for i in range(1, n):
            if s[i] == ")": # (肯定不用考虑了
                if s[i-1] == '(':
                    dp[i] = dp[i-2] + 2
                else:
                    prev = i - dp[i-1] - 1
                    if prev >= 0 and s[prev] == '(':
                        dp[i] = dp[i-1] + 2 + (dp[prev-1] if prev-1 >= 0 else 0)
                ans = max(ans, dp[i])
                
        return ans
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys


class Solution:
    def longestValidParentheses(self, s: str) -> int:
        n = len(s)
        if n < 2:
            return 0

        dp = [0] * n
        ans = 0

        for i in range(1, n):
            if s[i] == ")": # (肯定不用考虑了
                if s[i-1] == '(':
                    dp[i] = dp[i-2] + 2
                else:
                    prev = i - dp[i-1] - 1
                    if prev >= 0 and s[prev] == '(':
                        dp[i] = dp[i-1] + 2 + (dp[prev-1] if prev-1 >= 0 else 0)
                ans = max(ans, dp[i])
                
        return ans


for line in sys.stdin:
    # 不使用 strip()，保留可能为空的字符串；只去掉行尾换行符
    s = line.rstrip('\n').rstrip('\r')
    result = Solution().longestValidParentheses(s)
    print(result)
```
