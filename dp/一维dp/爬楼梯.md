# Problem Description

假设你正在爬楼梯，需要 n 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。请你计算一共有多少种不同的方法可以爬到楼顶。


# Solution
思考：dp数组定义，状态转移方程

# Code

## LC version

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # 考虑exception:小规模问题，遍历不到n
        if n == 1:
            return 1
        if n == 2:
            return 2
        
        # 定义dp数组：dp[i]表示爬到i阶时候的方法
        # 状态转移方程：dp[i] = dp[i-1] + dp[i-2]
        dp = [0] * (n+1)

        # base case
        dp[0] = 0
        dp[1] = 1
        dp[2] = 2

        for i in range(3, n+1):
            dp[i] = dp[i-1] + dp[i-2]

        return dp[n]
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys

class Solution:
    def climbStairs(self, n: int) -> int:
        # 考虑exception:小规模问题，遍历不到n
        if n == 1:
            return 1
        if n == 2:
            return 2
        
        # 定义dp数组：dp[i]表示爬到i阶时候的方法
        # 状态转移方程：dp[i] = dp[i-1] + dp[i-2]
        dp = [0] * (n+1)

        # base case
        dp[0] = 0
        dp[1] = 1
        dp[2] = 2

        for i in range(3, n+1):
            dp[i] = dp[i-1] + dp[i-2]

        return dp[n]

for line in sys.stdin:
    n = int(line.strip())
    result = Solution().climbStairs(n)
    print(result)
```
