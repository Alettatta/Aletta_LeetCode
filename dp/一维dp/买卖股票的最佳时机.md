# Problem Description
给定一个数组 prices，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0。


# Solution
股票系列问题状态定义：

```python
dp[i][k][0 or 1]
0 <= i <= n - 1, 1 <= k <= K
n 为天数，k 为交易数的上限，0 和 1 代表是否持有股票。
```

本题 k = 1，每天只能进行一次交易，那么可以忽略这个参数：

```python
状态转移方程：
dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i]) # 第i天手里没有股票：昨天手里也没有股票，还是昨天手里的收益；昨天买入、今天卖出
dp[i][1] = max(dp[i-1][1], -prices[i]) # 第i天手里有股票：昨天手里就持有股票，还是昨天手里的收益；昨天没有持有，今天买入、单纯花费

base case：i = 0
dp[0][0] = 0;
dp[0][1] = -prices[0];
```

# Code

## LC version

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        dp = [[0] * 2 for _ in range(n)]

        for i in range(n):
            # base case
            if i == 0:
                dp[i][0] = 0
                dp[i][1] = -prices[i]
                continue

            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
            dp[i][1] = max(dp[i-1][1], -prices[i])

        return dp[n-1][0]
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        dp = [[0] * 2 for _ in range(n)]

        for i in range(n):
            # base case
            if i == 0:
                dp[i][0] = 0
                dp[i][1] = -prices[i]
                continue

            dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])
            dp[i][1] = max(dp[i-1][1], -prices[i])

        return dp[n-1][0]

data = sys.stdin.read().split()
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    prices = [int(x) for x in data[idx:idx + n]]; idx += n
    result = Solution().maxProfit(prices)
    print(result)
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
