# Problem Description
给定一个非负整数 numRows，生成「杨辉三角」的前 numRows 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

具体来说，杨辉三角的第 0 行只有一个数 1；从第 1 行开始，每一行的首尾两个数都是 1，中间每个数等于上一行中相邻两个数之和。

# Solution

# Code

## ACM version

```python
import sys

# 状态转移方程：dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
class Solution:
    def generate(self, numRows):
        if numRows == 0:
            return []
            
        ans = []
        dp = [0] * numRows # 创建一个长度为numRows、所有元素初始化为0的列表

        for i in range(numRows): # 每次更新一行         
            dp[i] = 1 # 行尾置1                  
            for j in range(i - 1, 0, -1): # 倒着更新
                dp[j] = dp[j-1] + dp[j]
            dp[0] = 1 # 行首置1                     
            ans.append(dp[0 : i + 1]) # 取得第i行一共i+1个元素

        return ans


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    numRows = int(data[idx]); idx += 1
    ans = Solution().generate(numRows)
    for ls in ans:
        print(' '.join(str(x) for x in ls))
```


# Complexity Analysis
- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)
