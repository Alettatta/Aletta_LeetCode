# Problem Description
给定一个非负整数 numRows，生成「杨辉三角」的前 numRows 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

具体来说，杨辉三角的第 0 行只有一个数 1；从第 1 行开始，每一行的首尾两个数都是 1，中间每个数等于上一行中相邻两个数之和。



# Code

## LC version

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        ans = []
        # 考虑exception
        if numRows < 1:
            return ans
            
        # base case
        firstRow = [1]
        ans.append(firstRow)

        # 第i层
        for i in range(2, numRows + 1):
            prevRow = ans[-1] # 输入前一层计算下一层
            ans.append(self.generateNextRow(prevRow))
        
        return ans

    # 主要问题：如何根据上一层（左右上方）得到这个数字
    def generateNextRow(self, prevRow):
        curRow = [1] # 开头一定是 1
        for i in range(len(prevRow) - 1):
            curRow.append(prevRow[i] + prevRow[i + 1]) # curRow[i] = prevRow[i] + prevRow[i - 1]
        curRow.append(1) # 结尾一定是 1
        return curRow
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List

class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        ans = []
        # 考虑exception
        if numRows < 1:
            return ans
            
        # base case
        firstRow = [1]
        ans.append(firstRow)

        # 第i层
        for i in range(2, numRows + 1):
            prevRow = ans[-1] # 输入前一层计算下一层
            ans.append(self.generateNextRow(prevRow))
        
        return ans

    # 主要问题：如何根据上一层（左右上方）得到这个数字
    def generateNextRow(self, prevRow):
        curRow = [1] # 开头一定是 1
        for i in range(len(prevRow) - 1):
            curRow.append(prevRow[i] + prevRow[i + 1]) # curRow[i] = prevRow[i] + prevRow[i - 1]
        curRow.append(1) # 结尾一定是 1
        return curRow

for line in sys.stdin:
    numRows = int(line.strip())
    result = Solution().generate(numRows)
    for row in result:
        print(" ".join(str(x) for x in row))
```


# Complexity Analysis
- 时间复杂度：O(n^2)
- 空间复杂度：O(n^2)
