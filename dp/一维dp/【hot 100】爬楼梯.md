# Problem Description

假设你正在爬楼梯，需要 n 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。请你计算一共有多少种不同的方法可以爬到楼顶。


# Solution
思考：dp数组定义，状态转移方程

**注意【状态转移方程】的含义：动作（走1/2步）导致状态（第i阶方案）改变，按"最后一步是 1 还是 2"把路径分成两类，两类路径数相加**

**「为什么是dp[i] = dp[i - 1] + dp[i - 2]，从 i-2 阶到 i 阶，明明有 2 种走法（1+1 或直接 2），是不是要多算？」**

答案是：不能加这个 1，也不需要额外加。 关键在于理解「dp[i-2] 里已经包含了走到 i-2 的所有方法」，而「从 i-2 到 i 的走法」应该体现在转移方式上，到第 i 阶，按最后一步分类：

最后一步是 1 阶（从 i-1 上来）：前面必须已经走到 i-1，有 dp[i-1] 条完整路径。

最后一步是 2 阶（从 i-2 上来）：前面必须已经走到 i-2，有 dp[i-2] 条完整路径。

「从 i-2 走 1+1」这种走法，在分类时被归到了「最后一步是 1」那一类（dp[i-1]），而不是「最后一步是 2」那一类。



# Code

## ACM version

```python
import sys 


# 先枚举：n=1答案=1；n=2答案=2；n=3答案=3
class Solution:
    def climbStairs(self, n):
        # 基础情况枚举
        if n <= 2:
            return n
            
        # 定义状态转移方程：dp[i]为爬i阶的方法数总和
        dp = [0] * (n + 1)

        # base case
        dp[0] = 0
        dp[1] = 1
        dp[2] = 2
        for i in range(3, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2] # 从i-1/i-2的地方只能选择爬

        return dp[n]


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    ans = Solution().climbStairs(n)
    print(ans)
```

- 时间复杂度：O(n)
- 空间复杂度：O(n)
