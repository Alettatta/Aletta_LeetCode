# Problem Description
给你一个整数数组 nums，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案保证可以用 32 位 整数存储。



# Solution
原本想法：dp[i]: 以nums[i]结尾的乘积最大子数组，dp[i] = max(dp[i-1] * nums[i], dp[i-1]), dp[0] = nums[0]

问题是：nums=[2,3,-2]，按照你的算法：dp[0]=2，dp[1]=6，dp[2]=max(6*(-2),6)=6，结果 dp=[2,6,6]。可是题目定义的是：以 nums[i] 结尾，dp[2] 并没有以-2结尾，所以上面这个表示遇到负数会出问题

这道题正确的解法是：要**同时维护「以 nums[i] 结尾的最大子数组」和「以 nums[i] 结尾的最小子数组」（因为负负得正）**，以便适配 nums[i] 可能为负的情况。

        
# Code

## LC version

```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        n = len(nums)
        ans = float('-inf')
        if n == 0:
            return 0

        dp1 = [0] * n # 定义：以 nums[i] 结尾的子数组，乘积最小为 dp1[i]
        dp2 = [0] * n # 定义：以 nums[i] 结尾的子数组，乘积最大为 dp2[i]
        dp1[0] = nums[0]
        dp2[0] = nums[0]
        
        for i in range(1, n):
            dp1[i] = min(dp1[i-1] * nums[i], dp2[i-1] * nums[i], nums[i])
            dp2[i] = max(dp1[i-1] * nums[i], dp2[i-1] * nums[i], nums[i])

        for i in range(n):
            ans = max(ans, dp2[i])

        return ans
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        n = len(nums)
        ans = float('-inf')
        if n == 0:
            return 0

        dp1 = [0] * n # 定义：以 nums[i] 结尾的子数组，乘积最小为 dp1[i]
        dp2 = [0] * n # 定义：以 nums[i] 结尾的子数组，乘积最大为 dp2[i]
        dp1[0] = nums[0]
        dp2[0] = nums[0]
        
        for i in range(1, n):
            dp1[i] = min(dp1[i-1] * nums[i], dp2[i-1] * nums[i], nums[i])
            dp2[i] = max(dp1[i-1] * nums[i], dp2[i-1] * nums[i], nums[i])

        for i in range(n):
            ans = max(ans, dp2[i])

        return ans

data = sys.stdin.read().split()
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    nums = [int(x) for x in data[idx:idx + n]]; idx += n
    result = Solution().maxProduct(nums)
    print(result)
```
