# Problem Description
给定一个数组 prices，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0。


# Solution
首先定义状态转移方程dp[i]：第i天卖出的时候可以获得的最大利润，那么需要在price[0……i-1]找一个最小成本价；即dp[i] = prices[i] - min(prices[0..i-1])

最小成本价如何得到？minPrice = min(minPrice, prices[i])

第i天可以选择卖还是不卖：dp[i] = max(dp[i - 1], prices[i] - minPrice)

# Code

## ACM version

```python
import sys 


class Solution:
    def maxProfit(self, prices):
        if not prices:
            return 0 
        n = len(prices) # 一共有几天，只能在这几天里面操作
        dp = [0] * n

        minPrice = prices[0]
        for i in range(1, n):
            minPrice = min(minPrice, prices[i])
            dp[i] = max(dp[i - 1], prices[i] - minPrice)

        return max(dp)


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    prices = list(map(int, data[idx].split())); idx += 1
    ans = Solution().maxProfit(prices)
    print(ans)
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
