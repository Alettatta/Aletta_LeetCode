# Problem Description

给你一个整数数组 nums，找到其中最长严格递增子序列的长度。

子序列 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。


# Solution

dp[i]=以nums[i]结尾的最长递增子序列长度（而不是前缀，所以是dp[i] = max(dp[i]……)）

dp[i] = max(dp[j] + 1)，对所有 j < i 且 nums[j] < nums[i]；如果没有任何 j 满足，dp[i] = 1（自己单独成序列）

# Code

## LC version

```python
class Solution:
    def lengthOfLIS(self, nums):
        if not nums:
            return 0
        n = len(nums)
        dp = [1] * n # 长度至少为1
        for i in range(1, n):
            for j in range(i):
                if nums[j] < nums[i]:   # 对于当前的i：j有多个候选值，需要取最大的，所以是dp[i]
                    dp[i] = max(dp[i], dp[j] + 1)
        return max(dp)
```

# Complexity Analysis
- 时间复杂度：O(n^2)
- 空间复杂度：O(n)
