# Problem Description

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

给定一个代表每个房屋存放金额的非负整数数组，计算你不触动警报装置的情况下，一夜之内能够偷窃到的最高金额。


# Solution
dp[i]=偷到第i个屋子时候的最高金额，dp[i] = max(dp[i-2]+nums[i],dp[i-1])

定义dp[0]和dp[1]的时候不用多想，因为dp本来就是偷到第i个屋子的时候的最大金额（不用管这个偷不偷）

另外如果n==1，无法遍历range，这是一个特殊情况需要拎出来


# Code

## LC version

```python
class Solution:
    def rob(self, nums):
        if not nums:
            return 0
        n = len(nums)
        dp = [0] * n

        if n == 1:
            return nums[0]
            
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])
        
        for i in range(2, n):
            dp[i] = max(dp[i-2]+nums[i],dp[i-1])
        return dp[n - 1]
```



# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
