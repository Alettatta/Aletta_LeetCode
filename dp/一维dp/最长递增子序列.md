# Problem Description

给你一个整数数组 nums，找到其中最长严格递增子序列的长度。

子序列 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。


# Solution

定性：状态是索引 i 的位置的最长子序列长度，选择是往后遍历时候子序列长度变化，属于 dp 问题。

尝试使用 dp 数组：dp[i] 表示以 nums[i] 这个数结尾的最长递增子序列（注意这个子序列不一定连续，只是子集的意思）的长度

base case：dp[i] 初始值为 1，因为以 nums[i] 结尾的最长递增子序列起码要包含它自己。

关键问题是：如何求出 dp[i]？或者说，已知 dp[0……i-1]，如何求出 dp[i]？只要找到距离 i 最近的一个比 nums[i] 小的数字位置 j，然后 dp[i] = max(dp[i], dp[j] + 1) 即可

我们的最终结果（子序列的最大长度）应该是 dp 数组中的最大值。

# Code

## LC version

```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        # 定义dp[i]：以nums[i]结尾的最长递增子序列的长度
        dp = [1] * len(nums) # 因为求max，初始化小一点，以 nums[i] 结尾的最长递增子序列起码要包含它自己，为1可以

        # 求dp
        for i in range(len(nums)):
            for j in range(i):
                if nums[i] > nums[j]:
                    dp[i] = max(dp[i], dp[j] + 1)

        # 求总体的max
        ans = 0
        for i in range(len(dp)):
            ans = max(ans, dp[i])

        return ans
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List

class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        # 定义dp[i]：以nums[i]结尾的最长递增子序列的长度
        dp = [1] * len(nums)

        # 求dp
        for i in range(len(nums)):
            for j in range(i):
                if nums[i] > nums[j]:
                    dp[i] = max(dp[i], dp[j] + 1)

        # 求总体的max
        ans = 0
        for i in range(len(dp)):
            ans = max(ans, dp[i])

        return ans

for line in sys.stdin:
    n = int(line.strip())
    nums = list(map(int, sys.stdin.readline().strip().split()))
    result = Solution().lengthOfLIS(nums)
    print(result)
```
