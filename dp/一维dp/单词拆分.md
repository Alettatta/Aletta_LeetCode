# Problem Description

给你一个字符串 s 和一个字符串列表 wordDict 作为字典。请你判断是否可以利用字典中出现的单词拼接出 s。

注意：不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。


# Solution
本题同样可以用回溯算法做：子集/排列问题，且无重复元素可复用

```python
class Solution:
    def __init__(self):
        self.res = []
        self.track = []
    
    def permuteRepeat(self, nums: List[int]) -> List[List[int]]:
        self.backtrack(nums)
        return self.res

    # 回溯算法核心函数
    def backtrack(self, nums: List[int]) -> None:
        # base case，到达叶子节点
        if len(self.track) == len(nums):
            # 收集叶子节点上的值
            self.res.append(self.track[:])
            return

        # 回溯算法标准框架
        for i in range(len(nums)):
            # 做选择
            self.track.append(nums[i])
            # 进入下一层回溯树
            self.backtrack(nums)
            # 取消选择
            self.track.pop()
```

dp的视角：dp[i]表示字符串 s 的前 i 个字符（即 s[0:i]）能否被 wordDict 中的单词拼出————True/False

初始状态：dp[0] = True（空字符串总能被拼出）；最终的答案是 dp[n]

状态转移方程：对于每个位置 i（从 1 到 n），我们检查是否存在一个分割点 j（0 <= j < i），使得：dp[j] == True（**前缀** s[0:j] 可以被拼出），且**子串** s[j:i] 在字典中，若存在这样的 j，则 dp[i] = True。

# Code

## LC version

```python
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True # 空字符串肯定可被拼出来
        
        wordSet = set(wordDict)  # 用集合加速查找

        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] and s[j:i] in wordSet: # 前缀True、后面被分割的部分都有了
                    dp[i] = True
                    break # 找到一个分割点即可

        return dp[n]
```

集合加速查找的原因：列表是 O(n)；集合底层是哈希表 O(1)

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        n = len(s)
        dp = [False] * (n + 1)
        dp[0] = True # 空字符串肯定可被拼出来
        
        wordSet = set(wordDict)  # 用集合加速查找

        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] and s[j:i] in wordSet: # 前缀True、后面被分割的部分都有了
                    dp[i] = True
                    break # 找到一个分割点即可

        return dp[n]


def chomp(line: str) -> str:
    return line.rstrip("\n").rstrip("\r")


for line in sys.stdin:
    s = chomp(line)
    n_line = sys.stdin.readline()
    if not n_line:
        break
    n = int(n_line.strip())
    wordDict = []
    for _ in range(n):
        wordDict.append(chomp(sys.stdin.readline()))
    result = Solution().wordBreak(s, wordDict)
    print("true" if result else "false")
```


# Complexity Analysis
- 时间复杂度：O(n^2)
- 空间复杂度：O(n)
