# Problem Description
给你一个整数数组 nums，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组 是数组中的一个连续部分。

# Solution
首先思考dp数组含义——dp[i] = nums[i] 结尾的连续子数组的最大和（而不用从nums[0]开始）

状态转移的点在于，nums[i]肯定要，那么前面要不要继续接——dp[i] = max(nums[i], dp[i - 1] + nums[i])

# Code

## LC version

```python
class Solution:
    def maxSubArray(self, nums):
        if not nums:
            return 0
        n = len(nums)
        dp = [0] * n

        dp[0] = nums[0] # 初始化数组第一个数字
        for i in range(1, n):
            dp[i] = max(nums[i], dp[i - 1] + nums[i])
            
        return max(dp)
```

# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
