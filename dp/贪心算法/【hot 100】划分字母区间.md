# Problem Description
给你一个字符串 s。我们要把这个字符串划分为尽可能多的片段，要求同一字母最多出现在一个片段中。

返回一个表示每个字符串片段长度的列表，片段顺序按照其在 s 中出现的顺序排列。


# Solution
同一字母最多出现在一个片段中：每个字母最后出现的地方——**贪心，每个片段尽可能短，保证下个片段没有重复元素即可**（切得越早，片段数越多；但不能提前切——如果切的位置小于某个字母的最后出现位置，那个字母就会跨片段，违反约束；所以"最早能切的位置"就是"当前片段内所有字母最后出现位置的最大值"，此时切是唯一合法且最优的。）

先扫一遍，记录每个字母最后出现的下标 last[c]。

再扫一遍，维护当前片段的右边界 end：遍历到 i，end = max(end, last[s[i]])（当前片段至少要到 s[i] 最后出现的位置）；当 i == end，说明当前片段内所有字母的最后出现位置都已包含，可以切一刀，记录长度。

# Code

## LC version

```python
class Solution:
    def partitionLabels(self, s):
        last = {}
        for idx, char in enumerate(s):
            last[char] = idx# 扩展右边界到 c 的最后出现位置

        ans = []
        start = 0
        end = 0 # 当前片段起点和右边界

        for idx, char in enumerate(s):
            end = max(end, last[char])# 扩展右边界到 char 的最后出现位置
            if idx == end:
                ans.append(end - start + 1)
                start = end + 1

        return ans
```

# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
