# Problem Description
给你一个字符串 s。我们要把这个字符串划分为尽可能多的片段，要求同一字母最多出现在一个片段中。

返回一个表示每个字符串片段长度的列表，片段顺序按照其在 s 中出现的顺序排列。


# Solution

题目要求把字符串切成尽可能多的片段，且同一字母只能出现在一个片段中。换句话说，一旦某个字母 c 出现在了当前片段里，那 c 在整个字符串中所有的出现位置都必须被当前片段包住。这就相当于，每个字母都有一个「出现范围」，比如字母 a 第一次出现在下标 0，最后一次出现在下标 8，那它的范围就是 [0, 8]。题目要求的其实就是**把这些范围有重叠的字母分到同一组**，最终得到若干互不相交的片段。

具体做法是两次线性扫描。第一次扫描预处理出 last[c]，即每个字母在 s 中最后一次出现的下标。第二次扫描维护当前片段的起点 start 和终点 end：每遇到一个字符，就用它的 last 值来更新 end；当遍历指针 i 走到 end 时，说明当前片段内所有字母都已经闭合了，此时贪心地切一刀，开始下一段。

为什么贪心是对的？因为片段已经满足了约束（所有出现过的字母都被包住了），继续往右扩展没有任何收益，及时切割才能给后续片段留出更多空间。

# Code

## LC version

```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        n = len(s)
        last = [0] * 26 # 记录每个字母最后一次出现的位置
        for i in range(n):
            last[ord(s[i]) - ord('a')] = i

        ans = []
        start, end = 0, 0 # 当前片段的起点和终点
        for i in range(n):
            end = max(end, last[ord(s[i]) - ord('a')])
            if i == end: # 走到终点，说明片段内所有字母都已闭合，切一刀
                ans.append(end - start + 1)
                start = i + 1

        return ans
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        n = len(s)
        last = [0] * 26 # 记录每个字母最后一次出现的位置
        for i in range(n):
            last[ord(s[i]) - ord('a')] = i

        ans = []
        start, end = 0, 0 # 当前片段的起点和终点
        for i in range(n):
            end = max(end, last[ord(s[i]) - ord('a')])
            if i == end: # 走到终点，说明片段内所有字母都已闭合，切一刀
                ans.append(end - start + 1)
                start = i + 1

        return ans

for line in sys.stdin:
    s = line.rstrip('\n')
    result = Solution().partitionLabels(s)
    print(len(result))
    print(' '.join(str(x) for x in result))
```

- 时间复杂度：O(n)
- 空间复杂度：O(1)
