# Problem Description
路径 被定义为一条从树中任意节点出发，沿父节点 - 子节点连接，达到任意节点的序列。同一个节点在一条路径序列中至多出现一次。该路径至少包含一个节点，且不一定经过根节点。

路径和 是路径中各节点值的总和。

给你一个二叉树的根节点 root，返回其最大路径和，即所有可能路径中路径和的最大值。

```python
例子：[1,2,3]
text
    1
   / \
  2   3
所有可能的路径：

路径	节点值	路径和
单个节点：2	[2]	2
单个节点：1	[1]	1
单个节点：3	[3]	3
2 → 1	[2, 1]	2+1=3
1 → 3	[1, 3]	1+3=4
2 → 1 → 3	[2, 1, 3]	2+1+3=6 ✅
最大路径和 = 6（路径 2→1→3）
```

# Solution
可以使用递归方法，全局的最大路径和 -> max(每个节点的最大路径和) -> 所以需要用一全局变量记录每一个结点的情况

每个节点：root.val + max(0, left贡献) + max(0, right贡献)（经过父节点的路径 = 左贡献 + 父节点值 + 右贡献），递归函数的职责就是计算单边的贡献

后序方法，因为我们需要先知道左右情况才能知道root



# Code

## LC version

```python
# 遍历所有节点路径取最大值
class Solution:
    def maxPathSum(self, root):
        self.ans = float('-inf') # 因为要最大值
        self.dfs(root)
        return self.ans

    def dfs(self, node): # return的是直上直下路径的最大值（单左/右），要给单路径left/right用
        if node is None:
            return 0
        left = max(self.dfs(node.left), 0) # 左右子树如果有负数直接停下
        right = max(self.dfs(node.right), 0)
        self.ans = max(self.ans, node.val + left + right) # 但是ans可以折角，所以和return不一样
        return node.val + max(left, right)
```



# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
