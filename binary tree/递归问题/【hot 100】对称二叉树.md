# Problem Description
给定一个二叉树的根节点 root，检查它是否轴对称（即沿中心镜像对称）。


# Key Points
递归本质：把规模较大的问题分解成规模较小的问题和，然后通过子问题的解得到原问题的解，我们可以称这种思维模式为「分解问题」。

如果你想用「分解问题」的思维模式来写递归算法，那么这个递归函数一定要有一个清晰的定义，说明这个函数参数的含义是什么，返回什么结果。


# Solution
每个节点需要检验left.val是不是==right.val

然后检验下一层，所以使用递归

PS：拆开两个函数写是因为isSymmetric只有一个输入值root，但是检验这件事需要2个输入值，当原本函数无法满足的时候才会再写新函数


# Code

## LC version

```python
# 轴对称：所有节点的left和right的val是一样的；遍历所有节点都要满足这个
class Solution:
    def isSymmetric(self, root):
        if root is None:
            return True
        return self.check(root.left, root.right)

    def check(self, left, right):
        # 特殊情况
        if left is None or right is None:
            return left == right
        # base case
        if left.val != right.val: 
            return False
        # 岔递归下去
        return self.check(left.right, right.left) and self.check(left.left, right.right)
```



# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
