# Problem Description
给定一个二叉树的根节点 root，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

换句话说，对二叉树的每一层，返回该层最右侧的那个节点的值。



# Solution
找每一层最右边节点并返回

注意，不一定都在右子树上，比如有一层没有右子树，返回的就是左子树上最右边的节点


# Code

## LC version

```python
class Solution:
    def rightSideView(self, root):
        if root is None:
            return []
            
        left_view = self.rightSideView(root.left)
        right_view = self.rightSideView(root.right)
        tail = left_view[len(right_view):] # 右子树覆盖不到的层，由左子树补上
        
        return [root.val] + right_view + tail       
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
