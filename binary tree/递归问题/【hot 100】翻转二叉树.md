# Problem Description
给你一棵二叉树的根节点 root，翻转这棵二叉树，并返回其根节点。

翻转一棵二叉树指的是：将每个节点的左右子节点互换。



# Solution
每个节点需要干什么：交换left和right（注意交换的是整个节点而不是val，因为要递归他们的left、right）

然后节点的left和right孩子都要这样


# Code

## LC version

```python
# 遍历所有节点，每个节点的左右孩子val互换

class Solution:
    def invertTree(self, root):
        if root is None:
            return None
        root.left, root.right = root.right, root.left
        self.invertTree(root.left) # 递归处理左右子树
        self.invertTree(root.right)
        return root
```




# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
