# Problem Description

给定一个二叉树，找到该树中两个指定节点的最近公共祖先。

百度百科中最近公共祖先的定义为：「对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。」




# Solution
如果一个节点能够在它的左右子树中分别找到 p 和 q，则该节点为 LCA（Lowest Common Ancestor） 节点。那不就是给定root，p和q的值，看能不能找到？

lowestCommonAncestor(node, p, q)的含义：在以 node 为根的子树里，p、q 的"汇总信息"而不是LCA

都没有 → None

只找到 p 或只找到 q → 返回找到的那个节点（比如命中root is p，会返回p）

都找到，且已确定 LCA → 返回那个 LCA

# Code

## LC version

```python
# LCA情况：这棵树不存在、pq不存在（返回None）/是pq中的一个/pq要找其他节点（说明pq都是这个节点的孩子）

class Solution:
    def lowestCommonAncestor(self, root, p, q):
        if root is None or root is p or root is q:
            return root

        # 看能不能在左右子树里找到
        left  = self.lowestCommonAncestor(root.left,  p, q)
        right = self.lowestCommonAncestor(root.right, p, q)

        if left and right: # pq分居root两侧，LCA是root，left和right分别对应p和q
            return root

        # 肯定有一侧是None，说明pq分居同侧/不存在
        return left if left else right
```



# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
