# Problem Description
给你一个整数数组 nums，其中元素按 严格升序 排列，请你将其转换为一棵 高度平衡 的二叉搜索树。

高度平衡 二叉树是指每个节点的左右两个子树的高度差的绝对值不超过 1 的二叉树。

# Solution
中间值做root，左右递归思维构造（需要知道区间索引），类似二分查找

上述因为是二分查找，所以自己就可以保证高度平衡，两边一样长


# Code

## ACM version

```python
import sys 
from collections import deque


class TreeNode:
    def __init__(self, val = 0, left = None, right = None):
        self.val = val
        self.left = left
        self.right = right
    

class Solution:
    def sortedArrayToBST(self, nums):
        if len(nums) == 0:
            return None
            
        def build(left, right):
            if left > right: # 区间内一个节点都没有了
                return None
            mid = (left + right) // 2
            root = TreeNode(nums[mid])
            root.left  = build(left, mid - 1)  # 左半段
            root.right = build(mid + 1, right)
            return root

        return build(0, len(nums) - 1)


# 层序序列化root -> string，空节点用 # 表示，末尾的 # 去掉
def serialize(root):
    if root is None:
        return "#"

    ans = []
    q = deque([root])
    
    while q:
        node = q.popleft()
        if node is None:
            ans.append("#")
        else:
            ans.append(str(node.val))
            q.append(node.left)
            q.append(node.right)

    # 去掉末尾多余的 #
    while ans and ans[-1] == "#":
        ans.pop()
    return " ".join(ans)


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    nums = list(map(int, data[idx].split())); idx += 1
    root = Solution().sortedArrayToBST(nums)
    print(serialize(root))
```



# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
