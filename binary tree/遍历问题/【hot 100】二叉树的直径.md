# Problem Description
给定一棵二叉树的根节点 root，返回该二叉树的直径。

二叉树的直径是指树中任意两个节点之间最长路径的长度。这条路径可能经过也可能不经过根节点。

两节点之间路径的长度由它们之间边的数目表示。


# Solution
为什么说直径不一定会经过root，看下面这个例子：

```python
        1
       /
      2
     / \
    3   4
   /     \
  5       6
 /         \
7           8
```

求二叉树直径=max(每个节点的左右子树最大深度之和) -> 怎么求以 node 为根的子树高度

另外：注意设置self.maxDiameter这个每个节点都有的属性变量，另外更新它的位置在后序

# Code

## ACM version

```python
import sys 
from collections import deque

class TreeNode:
    def __init__(self, val = 0, left = None, right = None):
        self.val = val
        self.left = left
        self.right = right

# 求二叉树直径=max(每个节点的左右子树最大深度之和) -> 怎么求以 node 为根的子树高度
# 所以要加上每个节点的直径属性，然后取max
class Solution:
    def __init__(self):
        self.maxDiameter = 0
        
    def diameterOfBinaryTree(self, root):
        self.maxDepth(root)
        return self.maxDiameter

    def maxDepth(self, node):
        if node is None:
            return 0
        left = self.maxDepth(node.left)
        right = self.maxDepth(node.right)
        self.maxDiameter = max(left + right, self.maxDiameter) # 注意要更新node的最大直径
        return 1 + max(left, right)

# '1 2 3 4 5' -> BinaryTree
def build_tree(s):
    data = s.strip().split()
    if not data:
        return None
    if data[0] == '#':
        return None

    root = TreeNode(int(data[0]))
    idx = 1
    q = deque([root])

    while q:
        cur = q.popleft()
        if idx < len(data):
            t = data[idx]; idx += 1
            if t != '#':
                cur.left = TreeNode(int(t))
                q.append(cur.left)
        if idx < len(data):
            t = data[idx]; idx += 1
            if t != '#':
                cur.right = TreeNode(int(t))
                q.append(cur.right)

    return root

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    length = int(data[idx]); idx += 1
    s = data[idx] if idx < len(data) else ''; idx += 1
    root = build_tree(s)
    result = Solution().diameterOfBinaryTree(root)
    print(result)
```
