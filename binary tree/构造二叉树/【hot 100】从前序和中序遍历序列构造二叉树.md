# Problem Description
给定两个整数数组 preorder 和 inorder，其中 preorder 是二叉树的前序遍历，inorder 是同一棵树的中序遍历。请构造二叉树并返回其根节点。

# Solution
以这个例子为例：

```python
输入：preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出：[3,9,20,null,null,15,7]
```

preorder[0]定好root；在inorder中找到root索引；根据inorder的root左右情况确定左右子树有什么值；然后回到preorder中划分left、right，根据索引进行构造

难点在于preorder为了构造左右子树，下标如何确定？

# Code

## LC version

```python
# preorder[0] -> root；root在inorder中的位置确定左右子树有什么元素；回到preorder来确定子树的root
# 重要的是通过元素下标来确定哪一段作为左/右子树，中序inorder反映的信息比前序多
# 所以需要帮助函数helper，利用索引来构造BinaryTree

class Solution:
    def buildTree(self, preorder, inorder):
        if len(preorder) == 0 or len(inorder) == 0:
            return None
        idx = {value: index for index, value in enumerate(inorder)}
        
        def helper(preorder_left, preorder_right, inorder_left, inorder_right):
            # base case：区间内没有元素，告诉这是孩子节点
            if preorder_left > preorder_right: # 合法区间是pre_l<=pre_r，至少有一个元素
                return None
                
            root_val = preorder[preorder_left]
            root = TreeNode(root_val)
            mid = idx[root_val] # 寻找root在inorder中下标索引值
            
            left_size = mid - inorder_left # 左子树元素个数
    
            # 构造左子树
            root.left  = helper(preorder_left + 1, preorder_left + left_size, 
                                inorder_left, mid - 1)
            # 构造右子树
            root.right = helper(preorder_left + left_size + 1, preorder_right, 
                                mid + 1, inorder_right)
            
            return root

        return helper(0, len(preorder) - 1, 0, len(inorder) - 1)
```

# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
