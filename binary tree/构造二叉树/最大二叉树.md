# Problem
https://leetcode.cn/problems/maximum-binary-tree/


# Problem Description

给定一个不重复的整数数组 nums 。 最大二叉树 可以用下面的算法从 nums 递归地构建:

创建一个根节点，其值为 nums 中的最大值。
递归地在最大值 左边 的 子数组前缀上 构建左子树。
递归地在最大值 右边 的 子数组后缀上 构建右子树。
返回 nums 构建的 最大二叉树 。


# Solution

使用递归思维，最大值作为root，最大值左边的做left、右边的做right；每个子树都是这样构造

# Code

## LC version

```python
class Solution:
    def constructMaximumBinaryTree(self, nums):
        # 可以用递归解决，首先构造root
        # 接下来每个节点：max左边的数组是root.left，右边的是root.right
        if len(nums) == 0:
            return None

        p = max(nums)
        index = nums.index(p) # 获得最大值的索引，为了确定左右子树是啥
        root = TreeNode(p)

        root.left = self.constructMaximumBinaryTree(nums[:index])
        root.right = self.constructMaximumBinaryTree(nums[index + 1:])
        return root
```



# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
