# 归并排序
选出数组的中点，分别排好左右两边、合并即可

时间复杂度O(nlogn)（n层，每层复杂度logn）；空间复杂度O(n)（因为要建立ans）

```python
class Solution:
    def guibing(self, nums):
        if len(nums) <= 1:
            return nums

        mid = len(nums) // 2
        left = self.guibing(nums[:mid])
        right = self.guibing(nums[mid:])
        return self.merge(left, right)

    def merge(self, left, right):
        ans = []
        i, j = 0, 0
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                ans.append(left[i])
                i += 1
            else:
                ans.append(right[j])
                j += 1
        if i < len(left):
            ans.extend(left[i:])
        if j < len(right):
            ans.extend(right[j:])
        return ans
```

# 快速排序
（详细过程见ipad prodrafts）

快速排序确定一个pivot，目标是每次排序把pivot放到他在nums中正确的位置。

实现的具体方法是：这个正确的位置用i决定；为了区分大于和小于pivot的左右两段，引入low和high；另外用指针j来遍历数组，保证排序的时候从[low……i-1]是小于pivot的序列，[i……j-1]是大于等于pivot的序列，[j……high-1]是没有遍历的序列

初始pivot就从nums[high]开始；然后用j开始遍历，如果需要小于pivot的数字就和nums[i]交换位置，保证i维护左边小区间即可

时间复杂度O(nlogn)；空间复杂度O(logn)（递归本身调用栈，栈的深度是平均O(logn)）
```python
def quick_sort(nums):
    def partition(arr, low, high):
        pivot = arr[high]                 # 确定pivot，从最后一个数字开始
        i = low                           # i从边界low开始
        for j in range(low, high):        # j的遍历范围：i到high-1，因为arr[high]=pivot不用管
            if arr[j] < pivot:            # 维护好左边小区间，遇到小的就交换i/j对应的值，同时扩大左边界范围
                arr[i], arr[j] = arr[j], arr[i]
                i += 1
        arr[i], arr[high] = arr[high], arr[i]   # pivot放到正确位置
        return i                          # 返回pivot最终下标

    def sort(arr, low, high):
        if low >= high:
            return
        p = partition(arr, low, high)
        sort(arr, low, p - 1)            # 递归排序pivot左边序列
        sort(arr, p + 1, high)           # 递归排序pivot右边序列

    sort(nums, 0, len(nums) - 1)         # 调用
```
