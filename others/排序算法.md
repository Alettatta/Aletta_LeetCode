# 归并排序
选出数组的中点，分别排好左右两边、合并即可

时间复杂度O(nlogn)（n层，每层复杂度logn）；空间复杂度O(n)（因为要建立ans）

```python
class Solution:
    def guibing(self, nums):
        if len(nums) <= 1:
            return nums

        mid = len(nums) // 2
        left = self.guibing(nums[:mid])
        right = self.guibing(nums[mid:])
        return self.merge(left, right)

    def merge(self, left, right):
        ans = []
        i, j = 0, 0
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                ans.append(left[i])
                i += 1
            else:
                ans.append(right[j])
                j += 1
        if i < len(left):
            ans.extend(left[i:])
        if j < len(right):
            ans.extend(right[j:])
        return ans
```

# 快速排序

```python
def quick_sort(nums):
    def partition(arr, low, high):
        pivot = arr[high]                 # 选最后一个为基准
        i = low                           # i 指向"小于基准区"的边界
        for j in range(low, high):
            if arr[j] < pivot:
                arr[i], arr[j] = arr[j], arr[i]
                i += 1
        arr[i], arr[high] = arr[high], arr[i]   # 基准放到正确位置
        return i                          # 返回基准最终下标

    def sort(arr, low, high):
        if low >= high:
            return
        p = partition(arr, low, high)
        sort(arr, low, p - 1)
        sort(arr, p + 1, high)

    sort(nums, 0, len(nums) - 1)

```python
Lomuto 分区原理（关键）

以 arr = [3, 7, 2, 5, 1]，pivot = 1（最后一个）为例，i 维护"小于 pivot 的区域右边界"：
j 遍历，遇到 < pivot 的就和 arr[i] 交换，i 右移
最后把 pivot 换到 arr[i]，pivot 左边全小、右边全大
分区后 pivot 落在最终正确位置，且左边都 ≤ 它、右边都 ≥ 它，再对左右递归即可。
