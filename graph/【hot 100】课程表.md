# Problem
https://labuladong.online/zh/problem/leetcode/course-schedule/description/



# Problem Description
你这个学期必须选修 numCourses 门课程，记为 0 到 numCourses - 1 。

在选修某些课程之前需要一些先修课程。 先修课程按数组 prerequisites 给出，其中 prerequisites[i] = [ai, bi] ，表示如果要学习课程 ai 则 必须 先学习课程  bi 。

例如，先修课程对 [0, 1] 表示：想要学习课程 0 ，你需要先完成课程 1 。
请你判断是否可能完成所有课程的学习？如果可以，返回 true ；否则，返回 false 。



# Solution
需要先建立图（邻接矩阵），然后DFS



# Code

## ACM version

```python
import sys 


# 判断图中有没有环, numCourses = 2, prerequisites = [[1,0]]
class Solution:
    def canFinish(self, numCourses, prerequisites): # prerequisites: [ai, bi], bi -> ai
        if numCourses == 0:
            return True
            
        # 先建立邻接表: bi -> ai；bi是graph索引下标，比如 graph[bi] = [ai]
        graph = [[] for _ in range(numCourses)]
        for ai, bi in prerequisites:
            graph[bi].append(ai) 

        # 标记节点（课程）访问情况：0 未访问，1 访问中，2 已完成
        state = [0] * numCourses

        def dfs(u): # 从节点 u 出发，沿有向边走，能不能在不碰到环的情况下把所有能到达的节点都探完？
            if state[u] == 1:      # 走回当前正在访问的节点 → 有环 False
                return False
            if state[u] == 2:      # 已完成，确认无环
                return True

            state[u] = 1           # 标记"访问中"
            for v in graph[u]:
                if not dfs(v):     # 邻居有环 → 整体有环
                    return False
            state[u] = 2           # 所有邻居都探完，标记已完成
            return True

        # 对每个节点启动 DFS（图可能不连通）
        for i in range(numCourses):
            if not dfs(i): # dfs(i)为False说明有环
                return False
        return True


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    numCourses, m = map(int, data[idx].split()); idx += 1
    prerequisites = []
    for _ in range(m):
        prerequisites.append(list(map(int, data[idx].split())))
        idx += 1
    ans = Solution().canFinish(numCourses, prerequisites)
    print('true' if ans == True else 'false')
```

# Complexity Analysis
- 时间复杂度：O(mn)
- 空间复杂度：O(mn)
