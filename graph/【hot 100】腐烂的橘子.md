https://labuladong.online/zh/problem/leetcode/rotting-oranges/description/


# Problem Description
在一个 m x n 的网格 grid 中，每个单元格可以有以下三个值之一：

值 0 代表空单元格；

值 1 代表新鲜橘子；

值 2 代表腐烂的橘子。

每分钟，腐烂的橘子周围 4 个方向上相邻的新鲜橘子都会腐烂。

返回直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 -1。


# Solution
最短时间 -> BFS（类似层序遍历，使用deque）


# Code

## ACM version

```python
import sys 
from collections import deque


# 因为问的是最短时间，应该用BFS，DFS的话就不是最短
# 统计腐烂和新鲜的个数 -> 如果存在腐烂的，用queue更新腐烂列表向四周directions扩张

class Solution:
    def orangesRotting(self, grid):
        if not grid:
            return -1
            
        rows, cols = len(grid), len(grid[0])
        queue = deque()
        fresh = 0 # 统计新鲜橘子个数

        # 首先初始化，收集所有2位多源起点，统计新鲜的橘子
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2:
                    queue.append((r,c))
                elif grid[r][c] == 1:
                    fresh += 1

        # 如果fresh==0，说明全是新鲜的，不会烂
        if fresh == 0:
            return 0

        # 不然就肯定有2，会烂
        minutes = 0 # 腐烂的最短时间
        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        while queue and fresh > 0: # 因为fresh这个参数会改变，所以需要放进条件
            minutes += 1
            for _ in range(len(queue)): # 挨个处理腐烂的橘子
                r, c = queue.popleft()
                for dr, dc in directions: # dr: x; dc: y
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                        grid[nr][nc] = 2 # 腐烂
                        fresh -= 1
                        queue.append((nr, nc))

        return minutes if fresh == 0 else -1 # 保证全部腐烂，不然就烂不完、说明为-1


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    m, n = map(int, data[idx].split()); idx += 1
    grid = []
    for _ in range(m):
        grid.append(list(map(int, data[idx].split())))
        idx += 1
    ans = Solution().orangesRotting(grid)
    print(ans)
```


# Complexity Analysis
- 时间复杂度：O(mn)
- 空间复杂度：O(mn)
