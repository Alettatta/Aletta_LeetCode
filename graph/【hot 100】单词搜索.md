# Problem Description
给定一个 m x n 的二维字符网格 board 和一个字符串单词 word。如果 word 存在于网格中，返回 true；否则，返回 false。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中**相邻单元格是那些水平相邻或垂直相邻的单元格**。同一个单元格内的字母不允许被重复使用。


# Solution

岛屿变式+DFS

# Code


## ACM version


```python
import sys 


# 有点类似岛屿问题，现在需要找到的连通分量是word这个词
# 岛屿是"永久标记"，单词搜索必须"用完还回去"（回溯），因为这次没走通的格子，换个起点/换条路径可能还能找到

class Solution:
    def exist(self, board, word):
        if not board or not word:
            return False
            
        rows, cols = len(board), len(board[0])

        # 假设我站在格子(r,c)上，并且前面的word[0..k-1]都已经按顺序匹配成功了，请问：从这里继续往下走，能不能把word[k..]也匹配完？
        def dfs(r, c, k): # 输入board维度和需要匹配的字符的索引下标k
            # base case
            if r < 0 or r >= rows or c < 0 or c >= cols or board[r][c] != word[k]: # 越界 或 当前字符不匹配 → 失败
                return False
            if k == len(word) - 1: # 递归出口：如果最后一个字符也匹配上了，则成功
                return True

            # 标记当前格已使用：因为题目说同一个单元格内的字母不允许被重复使用
            tmp = board[r][c]
            board[r][c] = '#'
            
            # 四方向找下一个字符
            found = (dfs(r + 1, c, k + 1) or
                     dfs(r - 1, c, k + 1) or
                     dfs(r, c + 1, k + 1) or
                     dfs(r, c - 1, k + 1))

            # 回溯：恢复现场，供其他路径使用
            board[r][c] = tmp # tmp 存的是"我进来时这格子原本是什么字符"
            return found

        for r in range(rows):
            for c in range(cols):
                if dfs(r, c, 0):
                    return True

        return False


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    rows, cols = map(int, data[idx].split()); idx += 1
    board = []
    for _ in range(rows):
        board.append(list(data[idx].split()))
        idx += 1
    word = data[idx]
    idx += 1
    ans = Solution().exist(board, word)
    print('true' if ans == True else 'false')
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
