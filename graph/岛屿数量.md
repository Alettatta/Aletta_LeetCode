# Problem Description
给你一个由 '1'（陆地）和 '0'（水）组成的的二维网格，请你计算网格中岛屿的数量。

岛屿总是被水包围，并且每座岛屿只能由水平方向和/或竖直方向上相邻的陆地连接形成。

此外，你可以假设该网格的四条边均被水包围。


# Solution
DFS+岛屿沉没法


# Code

## ACM version

```python
import sys 


# 岛屿：周围一圈都是0；一个岛屿是一个连通分量——这个图中有多少个连通分量
# 遍历所有节点，每发现一个"没被访问过"的节点，分量数++1，然后把它所在的整个连通分量"标记为已访问"
# 使用DFS+沉岛法：遍历整个网格，每遇到一个 '1'，岛屿数 +1；用 DFS 把这个岛屿所有相连的 '1' 全部"沉没"成 '0'，避免重复计数。
class Solution:
    def numIslands(self, grid):
        if not grid: # 特殊情况
           return 0
            
        rows, cols = len(grid), len(grid[0]) # 记录遍历的矩阵维度

        # 深度优先搜索整个岛屿上的陆地，输入参数是矩阵维度
        # 从 (r,c) 出发，把与它相连的所有陆地全部处理掉
        def dfs(r, c):
            if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == '0': # 越界或不是陆地，直接返回
                return
            grid[r][c] = '0'  # 陆地被沉没
            dfs(r + 1, c) # 探索周围区域
            dfs(r - 1, c)
            dfs(r, c + 1)
            dfs(r, c - 1)

        count = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == '1':
                    count += 1
                    dfs(r,c)

        return count


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    rows, cols = map(int, data[idx].split()); idx += 1
    grid = []
    for _ in range(rows):
        grid.append(list(data[idx])) # 输入的本身就没有空格，不用split
        idx += 1
    ans = Solution().numIslands(grid)
    print(ans)
```
