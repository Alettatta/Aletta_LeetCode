# why stack & queue

数组和链表是结构基础，队列、栈这两种数据结构既可以使用链表也可以使用数组实现。

用数组实现，就要处理扩容缩容的问题；用链表实现，没有这个问题，但需要更多的内存空间存储节点指针。

PS：**一般用list实现即可**！

### 单调栈
这里的思路比较难，参见代码：输入一个数组 nums，请你返回一个等长的结果数组，结果数组中对应索引存储着下一个更大元素，如果没有更大的元素，就存 -1。

```python
def calculateGreaterElement(nums):
    n = len(nums)
    res = [0]*n
    s = []
    
    for i in range(n-1, -1, -1):# 倒着往栈里放
        while s and s[-1] <= nums[i]: # 比较栈里的元素和nums大小，新来元素大
            s.pop() # 就取代栈顶
        res[i] = -1 if not s else s[-1]
        s.append(nums[i]) # 把n-1位置数字放进来，用于左边n-2数字用
    return res
```

解读：假设 nums = [2,1,2,4,3]，建立一个栈 s = []，注意单调栈要倒着入栈（实际上是正着出栈，毕竟先进后出）
1. 第一个元素3，但是后面没东西，所以-1，入栈，s=[3]
2. 第二个元素4，矮个3pop，后面没东西，所以-1，入栈，s=[4]
3. 第三个元素2，2比4小，所以4，入栈，s=[4,2]（4那头才是栈底）
4. 第四个元素1，1比2小，所以2，入栈，s=[4,2,1]
5. 最后一个元素2，2比1大，矮个[2,1]都出，答案4

## 堆

二叉堆就是一种能够动态排序的数据结构。（所谓动态排序，就是说我们可以不断往数据结构里面添加或删除元素，数据结构会自动调整元素的位置，使得我们可以有序地从数据结构中读取元素，这是一般的排序算法做不到的。）

你可以认为二叉堆是一种特殊的二叉树，**这棵二叉树上的任意节点的值，都必须大于等于（或小于等于）其左右子树所有节点的值**。如果是**大于等于，我们称之为「大顶堆」，如果是小于等于，我们称之为「小顶堆」**。对于小顶堆，每个节点下方的所有节点的值都比它大，那么不难想象根节点就是整棵树上的最小值。同理，大顶堆的根节点就是整棵树上的最大值。所以二叉堆可以辅助我们**快速找到最大值或最小值**。

一般建立小顶堆即可，如果要建立大顶堆只要heapq.heappush(heap, -val)，pop的时候记得加负号还原val的原始值

模板如下：数据流中的第K大元素

```python
import heapq

class KthLargest:
    # 初始化，nums里面的元素依次加入堆，如果堆的大小超过K就弹出堆顶
    def __init__(self, k: int, nums: list[int]):
        self.k = k 
        self.heap = nums[:]
        heapq.heapify(self.heap) # 先整体堆化
        while len(self.heap) > k:
            heapq.heappop(self.heap) # 循环弹出，直到只剩 k 个

    # 把 val 加入堆；如果堆的大小超过 k，弹出堆顶；返回堆顶（第 k 大元素）
    def add(self, val: int) -> int:
        heapq.heappush(self.heap, val)
        if len(self.heap) > self.k:
            heapq.heappop(self.heap)
        return self.heap[0]
```

heapify 是一次性把一个无序列表整理成堆，而 heappush 是每次插入时增量维护（不超过总体容量k）。两者选一个即可。

堆按照元组进入：heapq.heappush(heap, (freq, num)) # freq是第一比较依据，其次才是num

# 附录：基本语法

其实队列和栈都是「操作受限」的数据结构。说它操作受限，主要是和基本的数组和链表相比，它们提供的 API 是不完整的。

比方说我们前面实现的数组和链表，增删查改的 API 都实现过了，你可以对任意一个索引元素进行增删查改，只要索引不越界，就随便你。

但是对于队列和栈，它们的操作是受限的：队列只能在一端插入元素，另一端删除元素（只允许在队尾插入元素，在队头删除元素）；栈只能在同一端插入和删除元素（在栈顶插入元素、删除元素）。

**队列是一种「先进先出」的数据结构，栈是一种「先进后出」的数据结构**
