# Problem Description

中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

例如 arr = [2,3,4] 的中位数是 3。
例如 arr = [2,3] 的中位数是 (2 + 3) / 2 = 2.5。
实现 MedianFinder 类：

MedianFinder()：初始化 MedianFinder 对象。
void addNum(int num)：将数据流中的整数 num 添加到数据结构中。
double findMedian()：返回到目前为止所有元素的中位数。
为保证答案唯一：判题端在比较输出时会对每个 findMedian 结果保留 5 位小数，请按相同精度构造你的实现。


# Solution
本题核心是使用2个优先级队列（堆）：

![堆](./photos/堆.png)

Python 的 heapq 只提供小顶堆（min heap），如何模拟大顶堆？

把所有数字都变成负数。例如原来的数字5、2、8变成-5、-2、-8放进小顶堆。因为小顶堆会认为-8 < -5 < -2，所以最先弹出的是-8，再取负号，于是就得到了原来的最大值8。


# Code

## LC version

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.large = [] # 小顶堆，保存较大的一半
        self.small = [] # 大顶堆，保存较小的一半

    def findMedian(self):
        if len(self.small) > len(self.large): # 因为是各切一半，只涉及奇偶数问题
            return -self.small[0]
        elif len(self.large) > len(self.small):
            return self.large[0]
        else:
            return (-self.small[0] + self.large[0]) / 2
            
    def addNum(self, num):
        heapq.heappush(self.small, -num) # 添加到大顶堆
        heapq.heappush(self.large, -heapq.heappop(self.small)) # 将大顶堆中的最大值移到小顶堆
        if len(self.large) > len(self.small): # 如果小顶堆的元素多于大顶堆，则需要平衡它们：保证 small 的数量应该 ≥ large，或者两者相等
            heapq.heappush(self.small, -heapq.heappop(self.large))
```

# Complexity Analysis
- 时间复杂度：O(logn)
- 空间复杂度：O(n)
