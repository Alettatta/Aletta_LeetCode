# Problem Description
给定一个只包含字符 '('，')'，'{'，'}'，'['，']' 的字符串 s，判断字符串是否有效。

有效字符串需满足：

左括号必须用相同类型的右括号闭合。

左括号必须以正确的顺序闭合。

每个右括号都有一个对应的相同类型的左括号。



# Code

## ACM version

细节注意：如果输入只有右括号，栈空的时候进行stack.pop()会报错，所以直接判断False；最后一定要stack为空，反之就没对上，所以是return not stack而不是return True

```python
import sys 

class Solution:
    def isValid(self, s: str) -> bool:
        # 使用栈，遇到左括号就入栈，遇到右括号就pop一个看能不能对应上，对不上就false，全部结束就是true
        if not s:
            return True
            
        stack = []
        for string in s:
            if string in ['(', '[', '{']:
                stack.append(string)
            if string in [')', ']', '}']:
                if not stack: #如果输入是 ")"，栈是空的（没有左括号），stack.pop() 会直接抛 IndexError
                    return False
                another = stack.pop()
                if another + string not in ['()', '[]', '{}']:
                    return False
                    
        return not stack # 循环结束后必须栈为空才有效，例如输入'('的情况，stack不为空，not stack为False

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    ans = Solution().isValid(data[idx])
    print('true') if ans == True else print('false')
    idx += 1
```

- 时间复杂度：O(n)
- 空间复杂度：O(n)
