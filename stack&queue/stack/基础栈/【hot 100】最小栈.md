# Problem
https://labuladong.online/zh/problem/leetcode/min-stack/description/


# Problem Description
设计一个支持 push、pop、top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类：

MinStack()：初始化堆栈对象。

void push(int val)：将元素 val 推入堆栈。

void pop()：删除堆栈顶部的元素。

int top()：获取堆栈顶部的元素。

int getMin()：获取堆栈中的最小元素。

push、pop、top 和 getMin 操作都必须以 O(1) 的时间复杂度运行。


# Solution

假设你有若干数字，你用一个 min 变量维护了其中的最小值，如果现在给这些数字中添加一个新数字，那么只要比较这个新数字和 min 的大小就可以得出最新的最小值。但如果现在从这些数字钟删除一个数字，你还能用 min 变量得到最小值吗？答案是不能，因为如果这个被删除的数字恰好是最小值，那么新的 min 变量应该更新为第二小的元素对吧，但是我没有记录第二小的元素是多少，所以只能把所有数字重新遍历一遍。

明确了难点再回到本题，就可以对症下药了。删除栈顶元素的时候，不确定新的最小值是多少，但楼下那哥们知道啊，他当时入栈时的最小值，就是现在的最小值呗。

所以这道题的关键就是，每个元素入栈时，还要记下来当前栈中的最小值。比方说，可以用一个额外的栈 minStk 来记录栈中每个元素入栈时的栈中的最小元素是多少，这样每次删除元素时就能快速得到剩余栈中的最小元素了。

# Code

## ACM version

```python
import sys 

class MinStack:
    def __init__(self):
        self.stack = []
        self.minStack = [] # 需要维护minStack来选择每一个数字入栈时的最小值

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.minStack or val <= self.minStack[-1]: # 如果最小栈里没有数字，加入第一个数字本身就是最小值
            self.minStack.append(val)
        else: # val > self.minStack[-1]，加入的数字比最小栈要大，当前最小值还是最小栈的头
            self.minStack.append(self.minStack[-1])

    def pop(self) -> None: # 删除堆栈顶部元素，最小栈也要去掉相应最小值
        self.stack.pop()
        self.minStack.pop()

    def top(self) -> int: # 获取堆栈顶部的元素
        return self.stack[-1]

    def getMin(self) -> int: # 获取堆栈中的最小元素->最小栈的top
        return self.minStack[-1]

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    num_ops = int(data[idx]); idx += 1 # 记录后续操作数量
    ms = MinStack() # 注意这里要创建对象，不然后面每个MinStack()都会重新创建
    for _ in range(num_ops):
        parts = data[idx].split() # ['push', '-2']
        op = parts[0]
        if op == "push": 
            num = int(parts[1])
            ms.push(num)
        elif op == 'pop':
            ms.pop() # pop不用print，因为上面函数的返回值是None
        elif op == 'top':
            print(ms.top())
        else: # op == 'getMin'
            print(ms.getMin())
        idx += 1
```



# Complexity Analysis
- 时间复杂度：O(1)
- 空间复杂度：O(n)
