# Problem Description
给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为：k[encoded_string]，表示其中方括号内部的 encoded_string 正好重复 k 次。注意 k 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 k，例如不会出现像 3a 或 2[4] 的输入。

测试用例保证输出的长度不会超过 10^5。


 # Solution

 核心思路：用一个栈存储「当前字符串」和「重复次数」的配对。遍历编码串时：

遇到数字：累积重复次数（注意可能是多位数，如 12[a]）

遇到 [：把当前积累的字符串和重复次数压栈，然后重置两者

遇到 ]：从栈中弹出之前的字符串和重复次数，把当前字符串重复若干次后拼接到弹出的字符串后面

遇到字母：拼接到当前字符串

以"3[a2[c]]"为例：
```python
 初始: num=0, res="", stack=[]

'3'  → num = 3
'['  → push (3, "")   stack=[(3,"")]     然后 num=0, res=""
'a'  → res = "a"
'2'  → num = 2
'['  → push (2, "a")  stack=[(3,""),(2,"a")]  然后 num=0, res=""
'c'  → res = "c"
']'  → pop (2,"a")  → res = "a" + "c"*2 = "acc"
']'  → pop (3,"")   → res = ""  + "acc"*3 = "accaccacc"

结果: "accaccacc" ✅
```

# Code

## ACM version


```python
import sys 

class Solution:
    def decodeString(self, s: str) -> str:
        # 用一个stack解决：比如"3[a2[c]]"
        # 遇到number（注意多位数比如12）：累计当前数字
        # 遇到[：把前面的num和res一起push，重置num=0，res=''
        # 遇到字母：拼到res
        # 遇到]：pop栈顶的[prev_num, prev_res]，把当前res重复prev_num次然后拼到prev_res后面
        stack = []
        res = ''
        num = 0

        for c in s:
            if c.isdigit(): # c是数字
                num = num * 10 + int(c) # 比如12，先进去1，要*10
            elif c == '[':
                stack.append((num, res))
                num = 0
                res = ''
            elif c == ']':
                prev_num, prev_res = stack.pop()
                res = prev_res + res * prev_num
            else: # c是字母
                res += c

        return res

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    ans = Solution().decodeString(data[idx])
    print(ans)
    idx += 1
```
