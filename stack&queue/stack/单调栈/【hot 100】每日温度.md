# Problem Description
给定一个整数数组 temperatures，表示每天的温度。返回一个数组 answer，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 0 来代替。

实现 dailyTemperatures(temperatures)，给定每日温度数组 temperatures，返回数组 answer，其中 answer[i] 表示从第 i 天起还要等多少天才会遇到更高的温度；若没有，则该位置为 0。


# 单调栈模板
单调栈模板问题：输入一个数组 nums，请你返回一个等长的结果数组，结果数组中对应索引存储着下一个更大元素，如果没有更大的元素，就存 -1。

比如说，输入一个数组 nums = [2,1,2,4,3]，你返回数组 [4,2,4,-1,-1]。因为第一个 2 后面比 2 大的数是 4; 1 后面比 1 大的数是 2；第二个 2 后面比 2 大的数是 4; 4 后面没有比 4 大的数，填 -1；3 后面没有比 3 大的数，填 -1。

这个问题可以这样抽象思考：把数组的元素想象成并列站立的人，元素大小想象成人的身高。这些人面对你站成一列，如何求元素「2」的下一个更大元素呢？很简单，如果能够看到元素「2」，那么他后面可见的第一个人就是「2」的下一个更大元素，因为比「2」小的元素身高不够，都被「2」挡住了，第一个露出来的就是答案。

![每日温度](../photos/单调栈.jpeg)

所以需要维护stack()，保证从栈顶到栈底是递减的（栈顶最大）；倒着遍历（保证右边是处理完的）；新来的元素（需要求右边最大值的）和栈顶元素对比，如果大的话就取代栈顶，一直弹出到栈为空或者栈顶元素更大；如果栈空那么这个位置答案为-1，反之就是栈顶元素

实现代码如下：

```python
def calculateGreaterElement(nums):
    n = len(nums)
    res = [0]*n
    s = []
    
    for i in range(n-1, -1, -1):# 倒着往栈里放
        while s and s[-1] <= nums[i]: # 比较栈里的元素和nums大小，新来元素大
            s.pop() # 就取代栈顶
        res[i] = -1 if not s else s[-1]
        s.append(nums[i]) # 把n-1位置数字放进来，用于左边n-2数字用
    return res
```

解读：假设 nums = [2,1,2,4,3]，建立一个栈 s = []，注意单调栈要倒着入栈（实际上是正着出栈，毕竟先进后出）
1. 第一个元素3，但是后面没东西，所以-1，入栈，s=[3]
2. 第二个元素4，矮个3pop，后面没东西，所以-1，入栈，s=[4]
3. 第三个元素2，2比4小，所以4，入栈，s=[4,2]（4那头才是栈底）
4. 第四个元素1，1比2小，所以2，入栈，s=[4,2,1]
5. 最后一个元素2，2比1大，矮个[2,1]都出，答案4
   
算法时间复杂度O(n),看似O(n^2)，总共有 n 个元素，每个元素都被 push 入栈了一次，而最多会被 pop 一次，没有任何冗余操作。


# Solution
上面例题是值入栈，这道题需要索引，所以是索引入栈

注意栈严格单调，所以是<=或者>=

## ACM version


```python
import sys 

class Solution:
    def dailyTemperatures(self, temperatures):
        stack = [] # 严格单调栈，从栈顶到栈底递减
        n = len(temperatures)
        ans = [0] * n # 默认值为0，每个位置对应一个答案

        for i in range(n - 1, -1, -1):
            # 如果栈里面有元素，就要pop到找到比当前位置大的元素
            while stack and temperatures[stack[-1]] <= temperatures[i]:
                stack.pop()
            ans[i] = 0 if not stack else stack[-1] - i
            stack.append(i)

        return ans

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    temperatures = list(map(int, data[idx].split()));idx += 1
    ans = Solution().dailyTemperatures(temperatures)
    print(' '.join(str(num) for num in ans)))
```
