# 写在前面的一道题

## Description
https://leetcode.cn/problems/reverse-words-in-a-string/description/

给你一个字符串 s ，请你反转字符串中 单词 的顺序。

单词 是由非空格字符组成的字符串。s 中使用至少一个空格将字符串中的 单词 分隔开。

返回 单词 顺序颠倒且 单词 之间用单个空格连接的结果字符串。

注意：输入字符串 s中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

## Solution

```python
# 首先reverse所有单词的顺序，从“hello world”变成“dlrow ollhe”
# 然后分别reverse单个单词，变成“world hello”
# PS: split之后得到的是数组，数组还原成 string 需要 join

class Solution:
    def reverseWords(self, s: str) -> str:
        words = s.split() # ['hello', 'world]
        s = ' '.join(words) # "hello world"
        s = s[::-1] # "dlrow ollhe"
        s = s.split() # ['dlrow', 'ollhe']
        s = [w[::-1] for w in s] # ['world', 'hello']
        s = ' '.join(s)
        return s
```

# Problem Description
给定一个 _n  _× n 的二维矩阵 matrix 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在**原地** 旋转图像，这意味着你需要直接修改输入的二维矩阵。请不要 使用另一个矩阵来旋转图像。


# Solution

常规的思路就是去寻找原始坐标和旋转后坐标的映射规律，但我们是否可以让思维跳跃跳跃，**尝试把矩阵进行反转、镜像对称等操作**，可能会出现新的突破口。

**先将 n x n 矩阵 matrix 按照左上到右下的对角线进行镜像对称，再对矩阵的每一行进行反转**，发现结果就是 matrix 顺时针旋转 90 度的结果。

按照左上到右下的对角线进行镜像对称（**主对角线i==j**）：

```python
for i in range(n): # 0,1,2
    for j in range(i, n): # 因为左上右下线是i==j，往后轴对称；第0行需要0；第1行需要0,1；第2行需要0,1,2
        matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
```


按照右上到左下的对角线进行镜像对称（**副对角线i+j==n-1**）：

```python
for i in range(n):
    for j in range(n - 1 -i): # 第0行需要0,1,2；第1行需要0,1；第2行需要2
        matrix[i][j], matrix[n - 1 - j][n - 1 - i] = matrix[n - 1 - i][n - 1 - j], matrix[i][j]
```


# Code

## LC version

```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        # 特殊规律：沿着左对角线翻转（行列标互换），然后反过来每一行即可
        
        n = len(matrix)
        
        # 沿着对角线镜像对称二维矩阵
        for i in range(n):
            for j in range(i, n): # j可遍历的数量越来越少
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        # 反过来每一行
        for row in matrix:
            self.reverse(row)

    def reverse(self, arr):
        i, j = 0, len(arr) - 1
        while j > i:
            arr[i], arr[j] = arr[j], arr[i]
            i += 1
            j -= 1
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

注意：row = row[::-1] 原地创建新列表但是 row = row.reverse()是原地方法修改matrix

```python
# 先对图像根据左上右下线镜像反转，然后每一行reverse
# e.g. matrix = [[1,2,3],[4,5,6],[7,8,9]]
# [[1,4,7],[2,5,8],[3,6,9]]
# [[7,4,1],[8,5,2,[9,6,3]]

import sys 

class Solution:
    def reverseImage(self, matrix):
        n = len(matrix)
        for i in range(n): # 0,1,2
            for j in range(i, n): # 因为左上右下线是i==j
               matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        for row in matrix:
            row.reverse()
        return matrix

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1 # matrix 维度
    matrix = []
    for _ in range(n):
        matrix.append(list(map(int, data[idx].split())))
        idx += 1 
    result = Solution().reverseImage(matrix) # [[7,4,1],[8,5,2,[9,6,3]]
    for ls in result:
        print(' '.join(map(str, ls))) # 注意：list无法直接join，只有string可以join
```
