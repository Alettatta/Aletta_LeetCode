# Problem Description
给定一个 m x n 的整数矩阵 matrix，如果矩阵中的某个元素为 0，则将其所在的整行和整列的所有元素都置为 0。

请使用原地算法完成这一修改。

# Solution

最朴素的思路是，用两个布尔数组 zeroRows[m] 和 zeroCols[n] 分别记录哪些行、哪些列需要置零。先扫一遍矩阵把含 0 的行号列号标记出来，再扫一遍根据标记置零即可。这样额外空间是 O(m+n)。

使用第一行和第一列作为标记数组；matrix[0][j] 标记第 j 列是否需要置零，matrix[i][0] 标记第 i 行是否需要置零，这样就不需要额外数组了（空间复杂度）

# Code

## ACM version


```python
# 使用第一行和第一列作为标记数组
# matrix[0][j] 标记第 j 列是否需要置零，matrix[i][0] 标记第 i 行是否需要置零，这样就不需要额外数组了（空间复杂度）

import sys 

class Solution:
    def putZero(self, matrix):
        m, n = len(matrix), len(matrix[0])
        # 先记录第一行和第一列本身是否含有0
        first_row_zero = any(matrix[0][j] == 0 for j in range(n))
        first_col_zero = any(matrix[i][0] == 0 for i in range(m))

        # 使用第一行/列作为标记数组
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0
                    matrix[0][j] = 0

        # 根据第一行/列标记置零
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        # 最后补上第一行/列的置零结果
        if first_col_zero:
            for i in range(m):
                matrix[i][0] = 0
        if first_row_zero:
            for j in range(n):
                matrix[0][j] = 0

        return matrix

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    m, n = map(int, data[idx].split()); idx += 1
    matrix = []
    for i in range(m):
        matrix.append(list(map(int, data[idx].split())))
        idx += 1
    ans = Solution().putZero(matrix)
    for i in range(m): # matrix[0][j], matrix[1][j]……
        print(' '.join(str(num) for num in matrix[i]))
```
