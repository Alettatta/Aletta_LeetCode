# Problem
https://leetcode.cn/problems/matrix-block-sum/


# Problem Description

给你一个 m x n 的矩阵 mat 和一个整数 k ，请你返回一个矩阵 answer ，其中每个 answer[i][j] 是所有满足下述条件的元素 mat[r][c] 的和： 

i - k <= r <= i + k, 

j - k <= c <= j + k 且

(r, c) 在矩阵内。
 


# Solution
本质求矩阵区域和，还是先建立一个前缀和矩阵（preSum[i][j] 记录 matrix 中子矩阵 [0, 0, i-1, j-1] 的元素和）

然后找具体是求哪个区域的矩阵和：求 mat[max(i-k,0),max(j-k,0),min(i+k,m-1),min(j+k,n-1)] 的区域元素和

# Code

## LC version

```python
class NumMatrix:
    # 定义：preSum[i][j] 记录 matrix 中子矩阵 [0, 0, i-1, j-1] 的元素和
    def __init__(self, matrix):
        m, n = len(matrix), len(matrix[0])
        self.preSum = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                self.preSum[i][j] = self.preSum[i - 1][j] + self.preSum[i][j - 1] + matrix[i - 1][j - 1] - self.preSum[i - 1][j - 1]
    
    # 计算子矩阵 [x1, y1, x2, y2] 的元素和
    def sumRegion(self, x1, y1, x2, y2):
        return (self.preSum[x2 + 1][y2 + 1] - self.preSum[x1][y2 + 1] -self.preSum[x2 + 1][y1] + self.preSum[x1][y1])


class Solution:
    # 求 mat[max(i-k,0),max(j-k,0),min(i+k,m-1),min(j+k,n-1)] 的区域元素和
    def matrixBlockSum(self, mat: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(mat), len(mat[0])
        ans = [[0]*(n) for _ in range(m)] # 注意不是前缀，n和m不用+1
        numMatrix = NumMatrix(mat)

        for i in range(m):
            for j in range(n):
                x1 = max(i - k, 0)
                y1 = max(j - k, 0)
                x2 = min(i + k, m - 1)
                y2 = min(j + k, n - 1)

                ans[i][j] = numMatrix.sumRegion(x1, y1, x2, y2)
        
        return ans
```

# Complexity Analysis
- 时间复杂度：O(1)
- 空间复杂度：O(mn)
