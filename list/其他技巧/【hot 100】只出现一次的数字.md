# Problem Description
给你一个非空整数数组 nums，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素并返回。

你必须设计并实现一个时间复杂度为 O(n) 且只使用常量额外空间的算法。



# Solution
这里就可以运用异或运算的性质：

一个数和它本身做异或运算结果为 0，即 a ^ a = 0；一个数和 0 做异或运算的结果为它本身，即 a ^ 0 = a。

对于这道题目，我们只要把所有数字进行异或，成对儿的数字就会变成 0，落单的数字和 0 做异或还是它本身，所以最后异或的结果就是只出现一次的元素。

# Code

## ACM version

```python
# 或（OR）：只要有一个为1，结果就是1
# 异或（XOR）：排除两个都为 1 的情况，只保留不一样的情况。
# 一个数和它本身做异或运算结果为 0，即 a ^ a = 0；（一样的情况，不要）
# 一个数和 0 做异或运算的结果为它本身，即 a ^ 0 = a（不一样的情况，留下）
# 成对出现的数字两两异或变成 0，所有 0 互相异或还是 0；最后 0 ^ 4 = 4，剩下的就是只出现一次的那个数。

import sys 

class Solution:
    def onlyOnce(self, nums):
        ans = 0
        for num in nums:
            ans = ans ^ num
        return ans

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    nums = list(map(int, data[idx].split())); idx += 1
    ans = Solution().onlyOnce(nums)
    print(ans)
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
