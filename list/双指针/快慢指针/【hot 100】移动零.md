# Problem Description
给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意，必须在**不复制数组的情况下原地对数组进行操作**。


# Key Points
使用快慢指针，快指针fast在前面探路，维护数组/链表**从开始到slow是“有效”（满足题目要求）的**，注意终止条件（while）


# Solution
注意只能原地修改数组，不能重新建一个来存储


# Code

## LC version

```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        # 快慢指针，fast在前面探路++1识别0，不是0的话slow移动到这个位置记录这个数字，是0的话记录0的个数，最后加上所有0

        fast = 0
        slow = 0
        
        while fast < len(nums):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1
            fast += 1

        for i in range(slow,len(nums)):
            nums[i] = 0

        return nums
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys 

class Solution:
    def moveZero(self, nums):
        # fast在前面探不是0的数字，用slow保存，保证nums[0…slow]不是0，最后slow+1到fast附上0
        if not nums:
            return

        fast = 0
        slow = 0

        while fast < len(nums):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1
            fast += 1

        for i in range(slow, fast): # 最后fast == len(nums)，取不到
            nums[i] = 0

        return nums

data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    nums = list(map(int, data[idx].split())); idx += 1
    result = Solution().moveZero(nums)
    print(' '.join(str(x) for x in result))
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
