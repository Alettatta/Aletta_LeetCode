# Problem Description
给你一个包含 n 个元素的数组 nums，数组中元素的颜色为红色、白色或蓝色。请你原地对它们进行排序，使得相同颜色的元素相邻，并按红色、白色、蓝色的顺序排列。

我们使用整数 0、1 和 2 分别表示红色、白色和蓝色。

必须在不使用库内置 sort 函数的情况下解决这个问题。

**进阶：你能想出一个仅使用常数空间的一趟扫描算法吗？**

数据范围：

n == nums.length

1 <= n <= 300

nums[i] 为 0、1 或 2


# Key Points
快慢指针核心：慢指针左侧是符合要求的部分，右边是待定的


# Solution
法1：两次移动0

注意：第一遍排完之后fast已经到达了边界条件，要退出，重新赋值fast=slow再开始

```python
class Solution:
    def sortColors(self, nums):
        n = len(nums)
        
        fast = slow = 0
        while fast < len(nums):
            if nums[fast] == 0: # 这样排完一轮slow指向0之后的位置:[0,0,2,1,1,2]
                nums[fast], nums[slow] = nums[slow], nums[fast]
                slow += 1
            fast += 1
                
        fast = slow
        while fast < len(nums):
            if nums[fast] == 1: # 这样排完之后1和2都处理好了
                nums[fast], nums[slow] = nums[slow], nums[fast]
                slow += 1
            fast += 1
```

法2：三个指针，两个慢指针两侧是符合要求的
```python
class Solution:
    def sortColors(self, nums):
        low, mid, high = 0, 0, len(nums) - 1
        while mid <= high:
            if nums[mid] == 0:
                nums[low], nums[mid] = nums[mid], nums[low]
                low += 1
                mid += 1
            elif nums[mid] == 1:
                mid += 1
            else:  # nums[mid] == 2
                nums[mid], nums[high] = nums[high], nums[mid]
                high -= 1
                # 注意：这里 mid 不 +1，换过来的数还没检查  
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys 
from typing import List

class Solution:
    def sortColors(self, nums: List[int]) -> None:
        if not nums:
            return nums
        slow = 0
        fast = 0
        while fast < len(nums): # nums[0,…slow]为[0,0,……]
            if  nums[fast] == 0:
                nums[fast], nums[slow] = nums[slow], nums[fast]
                slow += 1
            fast += 1
        for fast in range(slow, len(nums)):
            if  nums[fast] == 1:
                nums[fast], nums[slow] = nums[slow], nums[fast]
                slow += 1
            fast += 1
        return nums
        
data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    nums = list(map(int, data[idx].split())); idx += 1
    result = Solution().sortColors(nums)
    print(' '.join(str(x) for x in result))
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
