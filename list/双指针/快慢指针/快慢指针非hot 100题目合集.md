# 总领
## 一般思路
fast和slow双指针，fast在前面探路处理重复值，slow维护nums[0……slow]是有效的（满足题目要求）

## tricky problem
用纸笔模拟数组搜索过程：
1. fast++和slow++的位置
2. 判断条件是nums[fast]==还是!=nums[slow]
3. return值和fast、slow的数学关系

# 删除有序数组的重复项
## Description

https://leetcode.cn/problems/remove-duplicates-from-sorted-array/

给你一个 非严格递增排列 的数组 nums ，请你 原地 删除重复出现的元素，使每个元素 只出现一次 ，返回删除后数组的新长度。元素的 相对顺序 应该保持 一致 。然后返回 nums 中唯一元素的个数。

考虑 nums 的唯一元素的数量为 k。去重后，返回唯一元素的数量 k。

nums 的前 k 个元素应包含 排序后 的唯一数字。下标 k - 1 之后的剩余元素可以忽略。

## Solution

```python
# [1,2,2,3]
# fast前面探路，slow后面，如果slow==fast，把fast的值赋给slow的位置，保证nums[0……slow]有效

class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        # 处理特殊情况
        if not nums:
            return 0

        fast = 0, slow = 0
        while fast < len(nums):
            if nums[fast] != nums[slow]:
                slow += 1
                nums[slow] = nums[fast]
            fast += 1 # 跳过重复元素
        return slow + 1 # 有效长度加上nums[0]位置
```


# 删除有序数组的重复项II
## Description

https://leetcode.cn/problems/remove-duplicates-from-sorted-array-ii/description/

给你一个有序数组 nums ，请你 原地 删除重复出现的元素，使得出现次数超过两次的元素只出现两次 ，返回删除后数组的新长度。

不要使用额外的数组空间，你必须在 原地 修改输入数组 并在使用 O(1) 额外空间的条件下完成。

PS. 和上一题的区别是，这一题不删除重复元素，而是可以出现2次重复值，所以**前面2个数字肯定保留，从下标=2开始判断即可**

## Solution

```python
# fast在前面探路，第一二次遇到都没事，第三次就slow过来，放入下一个数字

class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        # 前面2个元素一定保留
        if len(nums) < 2:
            return len(nums)

        slow = 2 

        for fast in range(2, len(nums)):
            if nums[fast] != nums[slow - 2]: # 说明这一位有效，反之fast继续向前
                nums[slow] = nums[fast]
                slow += 1

        return slow
```



# 删除排序链表的重复元素
## Description

https://leetcode.cn/problems/remove-duplicates-from-sorted-list/description/

给定一个已排序的链表的头 head ， 删除所有重复的元素，使每个元素只出现一次 。返回 已排序的链表 。

PS. 注意链表和数组的区别：修改slow链接到fast时候，原本slow后续的链接要断掉，也就是slow.next = None

## Solution

```python
class Solution:
    def deleteDuplicates(self, head: ListNode | None) -> ListNode | None:
        if head is None:
            return head

        fast = head
        slow = head

        while fast is not None:
            if fast.val != slow.val:
                slow.next = fast
                slow = slow.next
            fast = fast.next
        slow.next = None # 断开和后面重复元素的链接

        return head
```


# 移除元素
## Description

https://leetcode.cn/problems/remove-element/description/

给你一个数组 nums 和一个值 val，你需要 原地 移除所有数值等于 val 的元素。元素的顺序可能发生改变。然后返回 nums 中与 val 不同的元素的数量。

假设 nums 中不等于 val 的元素数量为 k，要通过此题，您需要执行以下操作：

更改 nums 数组，使 nums 的前 k 个元素包含不等于 val 的元素。nums 的其余元素和 nums 的大小并不重要。

返回 k。

PS. 前面的题目找重复值，这里fast找值为val的即可

## Solution

```python
class Solution:
    def removeElement(self, nums: list[int], val: int) -> int:
        if not nums:
            return 0

        fast = 0
        slow = 0

        while fast < len(nums):
            if nums[fast] != val:
                nums[slow] = nums[fast]
                slow += 1
            fast += 1 # 我只要找不是val的数字，所以fast在前面只要探路不是val的数字

        return slow
```
