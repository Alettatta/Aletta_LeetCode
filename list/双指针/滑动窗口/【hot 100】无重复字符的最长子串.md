# Problem Description
给定一个字符串 s，请你找出其中不含有重复字符的 最长子串 的长度。


# Key Points
滑动窗口主要处理子串/子数组问题，三连问：
1. 什么时候扩大窗口（右移right）？窗口扩大时，要更新什么？
2. 什么时候缩小窗口（右移left）？窗口缩小时，要更新什么？
3. 什么时候更新结果？


# Code

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
# 找一个字符串的不含重复字符的最长子串长度，考虑滑动窗口
# 1. 啥时候扩大窗口？要更新什么
# 2. 啥时候缩小窗口？要更新什么
# 3. 什么时候更新结果
# right向右扩大窗口window->直到window中有键的值>=2，问题出在s[right]上
# left向右缩小窗口，更新window直到满足要求->更新答案

import sys

class Solution:
    def maxString(self, s):
        if not s:
            return 0
        left = 0; right = 0
        window ={}
        length = 0 
        
        while right < len(s):
            window[s[right]] = window.get(s[right], 0) + 1
            
            # 缩小窗口，问题一定出在s[right]与前面的一个字母重复，只要检验这个
            while window[s[right]] >= 2: # 注意用while遍历，而不是if
                window[s[left]] -= 1
                left += 1
        
            length = max(length, right - left + 1) # 是right-left+1要+1因为上面已经left++了，left指向的不是那个重复值了
            right += 1 # 一定放在这里，因为这个right还是有效值
                
        return length

data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    s = data[idx]; idx += 1
    ans = Solution().maxString(s)
    print(ans)
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
