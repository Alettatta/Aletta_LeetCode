# Problem Description
给定一个字符串 s，请你找出其中不含有重复字符的 最长子串 的长度。

# 第三轮注意
1. 收缩条件是window[s[right]]还是window[s[right - 1]]，相应的length = right - left还是什么
2. 更新ans的位置

# Key Points
滑动窗口主要处理子串/子数组问题，三连问：
1. 什么时候扩大窗口（右移right）？窗口扩大时，要更新什么？
2. 什么时候缩小窗口（右移left）？窗口缩小时，要更新什么？
3. 什么时候更新结果？

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout

```python
# 找一个字符串的不含重复字符的最长子串长度，考虑滑动窗口
# 1. 啥时候扩大窗口？要更新什么
# 2. 啥时候缩小窗口？要更新什么
# 3. 什么时候更新结果
# right向右扩大窗口window->直到window中有键的值>=2，问题出在s[right]上
# left向右缩小窗口，更新window直到满足要求->更新答案

import sys

class Solution:
    def lengthOfLongestSubstring(self, s):
        left = right = 0
        window = {}
        ans = 0
        
        while right < len(s):
            window[s[right]] = window.get(s[right], 0) + 1
            right += 1
            while window[s[right - 1]] > 1: # 刚加入的是s[right - 1]而不是s[right]；比如"abcabcbb"中，right指向b了但是加入的是a，left减去这个值指向b，长度为4-1=3
                window[s[left]] -= 1
                left += 1
                ans = max(ans, right - left)
        return ans

data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    s = data[idx]; idx += 1
    ans = Solution().maxString(s)
    print(ans)
```
