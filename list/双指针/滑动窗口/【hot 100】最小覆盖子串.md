# Problem Description
给定两个字符串 s 和 t，长度分别是 m 和 n，返回 s 中的最短窗口子串，使得该子串包含 t 中的每一个字符（包括重复字符）。如果没有这样的子串，返回空字符串 ""。

测试用例保证答案唯一。


# Key Points
滑动窗口主要处理子串/子数组问题，三连问：
1. 什么时候扩大窗口（右移right）？窗口扩大时，要更新什么？
2. 什么时候缩小窗口（右移left）？窗口缩小时，要更新什么？
3. 什么时候更新结果？

**ACM 模式的注意点：**

```python
# 滑动窗口处理子数组/子串问题：
# 1. 什么时候扩大窗口？扩大right需要更新什么？
# 2. 什么时候缩小窗口？缩小left需要更新什么？
# 3. 什么时候更新结果？
# 实现细节：准备left和right，维护区间[left, right)，一开始left=right=0没有有效字符，right扩大就有
# 根据t准备hashmap{}need->移动right扩大窗口window->更新window(PS.这里要判断valid是否满足)
# 如果window满足need(利用valid字符)->更新结果->缩小left，更新window

import sys 

class Solution:
    def minimalString(self, s, t):
        need = {}
        window = {}
        for ch in t:
            need[ch] = need.get(ch, 0) + 1 # 不能直接need[ch]++因为空字典，需要赋默认值0
        left = 0
        right = 0
        valid = 0
        start = 0
        length = float('inf') # 因为要求最小长度，所以初始化为正无穷

        while right < len(s):
            if s[right] in need:
                window[s[right]] = window.get(s[right], 0) + 1
                if window[s[right]] == need[s[right]]:
                    valid += 1
            right += 1 # 更新完再right++

            # 注意这里也是while而不是if，因为逐个移除left无效字符是遍历
            while valid == len(need): # 先更新结果s[left,right-1]再缩小left，但是我需要一个最小的left，所以这里要引入新变量来记录最小起始下标
                if right - left < length: # 更新结果
                    start = left
                    length = right - left # 因为right已经指向无效字符，所以长度应该是(right-1)-left+1
                if s[left] in need: # 缩小窗口
                    if need[s[left]] == window[s[left]]:
                        valid -= 1
                    window[s[left]] -= 1
                left += 1
                    
        return -1 if length == float('inf') else s[start: start + length]

data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    s = data[idx]; idx += 1
    t = data[idx]; idx += 1
    ans = Solution().minimalString(s, t)
    print(ans)
```
