# Problem Description
给定两个字符串 s 和 t，长度分别是 m 和 n，返回 s 中的最短窗口子串，使得该子串包含 t 中的每一个字符（包括重复字符）。如果没有这样的子串，返回空字符串 ""。

测试用例保证答案唯一。

# 第三轮注意点
1. 最小长度子串，用length记录
2. start来记录子串
3. 注意缩小窗口的条件是while valid == len(need)，因为窗口大小不固定，只要求全覆盖子串

# Key Points
滑动窗口主要处理子串/子数组问题，三连问：
1. 什么时候扩大窗口（右移right）？窗口扩大时，要更新什么？
2. 什么时候缩小窗口（右移left）？窗口缩小时，要更新什么？
3. 什么时候更新结果？

```python
# 滑动窗口处理子数组/子串问题：
# 1. 什么时候扩大窗口？扩大right需要更新什么？
# 2. 什么时候缩小窗口？缩小left需要更新什么？
# 3. 什么时候更新结果？
# 实现细节：准备left和right，维护区间[left, right)，一开始left=right=0没有有效字符，right扩大就有
# 根据t准备hashmap{}need->移动right扩大窗口window->更新window(PS.这里要判断valid是否满足)
# 如果window满足need(利用valid字符)->更新结果->缩小left，更新window

import sys 

class Solution:
    def minWindow(self, s, t):
        need = {}
        for ch in t:
            need[ch] = need.get(ch, 0) + 1

        left = right = 0
        valid = 0
        window = {}
        length = float('inf') # 求最小长度
        start = 0

        while right < len(s):
            # 扩大窗口
            if s[right] in need:
                window[s[right]] = window.get(s[right], 0) + 1
                if window[s[right]] == need[s[right]]:
                    valid += 1
            right += 1

            while valid == len(need):
                # 先更新结果
                if right - left < length:
                    start = left
                    length = min(length, right - left)
                # 再缩小窗口
                if s[left] in need:
                    if window[s[left]] == need[s[left]]:
                        valid -= 1
                    window[s[left]] -= 1
                left += 1

        return -1 if length == float('inf') else s[start: start + length]

data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    s = data[idx]; idx += 1
    t = data[idx]; idx += 1
    ans = Solution().minimalString(s, t)
    print(ans)
```
