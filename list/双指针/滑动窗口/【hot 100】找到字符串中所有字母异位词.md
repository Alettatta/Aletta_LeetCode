# Problem Description
给定两个字符串 s 和 p，找到 s 中所有 p 的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。


# Key Points
滑动窗口主要处理子串/子数组问题，三连问：
1. 什么时候扩大窗口（右移right）？窗口扩大时，要更新什么？
2. 什么时候缩小窗口（右移left）？窗口缩小时，要更新什么？
3. 什么时候更新结果？


# Solution
注意p给定说明window大小恒定，与经典模板的区分点在于满足结果的条件不一样


# Code

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
# 用滑动窗口遍历s，p相当于是need，但是这题滑动窗口长度固定为len(p)
# right扩大，直到窗口达到len(p)，如果此时window和need一样，ans.append(left)，更新window
# 如果不一样，right和left一起往前

import sys 

# 在s里面找p：扩大窗口(子串大小<len(p))；缩小窗口

class Solution:
    def findAnagrams(self, s, p):
        # 先确定要什么(hash)
        need = {}
        for ch in p:
            need[ch] = need.get(ch, 0) + 1

        ans = []
        window = {} # 顺序无所谓，记录字母即可(hash)
        left, right = 0, 0
        valid = 0 # 记录的是子串与要求异位词的匹配度

        while right < len(s):
            # 扩大窗口
            if s[right] in need:
                window[s[right]] = window.get(s[right], 0) + 1
                if window[s[right]] == need[s[right]]:
                    valid += 1
            right += 1

            # 缩小窗口：满足长度
            while right - left >= len(p):
                if valid == len(need): # 缩小窗口之前先记录答案
                    ans.append(left)
                if s[left] in need: # 缩小窗口，window发生变化
                    if need[s[left]] == window[s[left]]:
                        valid -= 1
                    window[s[left]] -= 1
                left += 1
        
        return ans
        
data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    s = data[idx]; idx += 1
    p = data[idx]; idx += 1
    ans = Solution().findAnagrams(s, p)
    print(' '.join(str(ch) for ch in ans)) if ans else print('NONE')
```

- 时间复杂度：O(n)
- 空间复杂度：O(n)
