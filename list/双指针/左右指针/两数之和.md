# 总领
这类问题如果**return 索引**，必须用**hashmap**解决；如果**return具体值**，可以**nums.sort()（注意这一步时间复杂度O(NlogN)）然后再用左右指针**

# 两数之和

https://leetcode.cn/problems/two-sum/description/

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出 和为目标值 target  的那 两个 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        # 数组不有序，同时不能修改位置
        map = {} # nums[i]:i
        for i in range(len(nums)):
            if target - nums[i] in map:
                return [i, map[target - nums[i]]]
            map[nums[i]] = i
        return []
```

# 两数之和II

https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/description/

给你一个下标从 1 开始的整数数组 numbers ，该数组已按 非递减顺序排列  ，请你从数组中找出满足相加之和等于目标数 target 的两个数。如果设这两个数分别是 numbers[index1] 和 numbers[index2] ，则 1 <= index1 < index2 <= numbers.length 。

以长度为 2 的整数数组 [index1, index2] 的形式返回这两个整数的下标 index1 和 index2。

你可以假设每个输入 只对应唯一的答案 ，而且你 不可以 重复使用相同的元素。

你所设计的解决方案必须只使用常量级的额外空间。

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        # 数组已经非递减，可以使用双指针
        left = 0
        right = len(nums) - 1
        while left < right: # left == right时候，使用了重复相同的元素，所以永远不成为结果
            if nums[left] + nums[right] < target:
                left += 1
            elif nums[left] + nums[right] > target:
                right -= 1
            else:
                return [left + 1, right + 1]
        return []
```

## 两数之和拓展（引申到三数之和）

解决进阶问题：nums 中可能有多对元素之和都等于 target，请你的算法返回所有和为 target 的元素对，其中不能出现重复。

nums = [1,3,1,2,2,3], target = 4，结果：[[1,3],[2,2]]（注意，我要求返回元素，而不是索引）

sort之后为[1,1,2,2,3,3]

```python
class Solution:
    def twoSumTarget(self, nums: List[int], target: int) -> List[List[int]]:
        nums.sort()
        left = 0
        right = len(nums) - 1
        ans = []
        while left < right:
            if nums[left] + nums[right] < target:
                left += 1
            elif nums[left] + nums[right] > target:
                right -= 1
            else: # 如果left和right不是重复元素再加入答案
                l, r = nums[left], nums[right]
                ans.append([l, r])
                # 注意left和right一直迭代而越界的问题
                while left < right and nums[left] == l: # 一开始必nums[left]==l，所以不断向下迭代
                    left += 1
                while left < right and nums[right] == r:
                    right -= 1
        return ans
# 时间复杂度O(N)，排序O(NlogN)，总体O(NlogN)
```
