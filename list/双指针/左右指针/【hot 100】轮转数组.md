# Problem Description
给你一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。

返回轮转后的数组。



# Solution
最直接的想法是再开一个数组，把每个 nums[i] 放到 (i + k) % n 的位置，再拷贝回去，但这样需要 O(n) 的额外空间。有没有办法原地完成轮转呢？

观察一下旋转的结构：把 nums 切成前 n - k 个元素 A 和后 k 个元素 B 两段，向右轮转 k 步之后，结果就是 B 拼上 A，即 [B, A]。所以旋转的本质是让两段交换位置。

直接交换两段不好做，但「反转某一段」是可以原地完成的。关键性质在于：把 [A, B] 整体反转一次得到 [B', A']（' 表示反转），此时 B 已经被甩到了前面、A 被甩到了后面，只是各自的内部顺序反了。再把前 k 个和后 n - k 个分别反转回来，就得到了 [B, A]。

以 nums = [1, 2, 3, 4, 5, 6, 7]，k = 3 为例：整体反转得 [7, 6, 5, 4, 3, 2, 1]；反转前 3 个得 [5, 6, 7, 4, 3, 2, 1]；反转后 4 个得 [5, 6, 7, 1, 2, 3, 4]，正是答案。

# Code


## ACM version

```python
# nums=[A,B]，结束后为[B,A]，切割位置nums[k]
# 可以先整体reverse[7,6,5,/4,3,2,1]，然后A和B分别reverse即可

import sys 

class Solution:
    def lunzhuanArray(self, nums, k):
        n = len(nums)
        k = k % n # k可能大于n，取模
        self.reverse(0, n - 1)
        self.reverse(0, k - 1)
        self.reverse(k, n - 1)
        return nums
        
    def reverse(self, left, right): # 翻转nums[left,…,right+1]
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
        
data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    n, k = map(int, data[idx].split()); idx += 1
    nums = list(map(int, data[idx].split())); idx += 1
    ans = Solution().lunzhuanArray(nums, k)
    print(' '.join(str(num) for num in ans))
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
