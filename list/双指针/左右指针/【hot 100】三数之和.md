# Problem Description
给你一个整数数组 nums，请你找出所有满足 i != j、i != k 且 j != k，同时 nums[i] + nums[j] + nums[k] == 0 的不同三元组 [nums[i], nums[j], nums[k]]。

为保证答案唯一，输出需满足以下约束：

每个三元组内部的元素必须按照非递减顺序排列，即 [a, b, c] 满足 a <= b <= c。

所有三元组之间按字典序升序排列：先比较第一个元素，若相同再比较第二个元素，若仍相同再比较第三个元素。

答案中不能包含重复的三元组。

数据范围：

3 <= nums.length <= 3000

-10^5 <= nums[i] <= 10^5

# Solution
不要忘了去重！！！内层外层都是！！！

# 第三轮问题
1. 注意要对nums[i]/nums[left]/nums[right]都要去重，nums[i]是直接continue，另外两个移动指针
2. 双指针循环条件要while left < right
3. 外层内层都要while left < right，因为外层是进入条件时候的判断，后面可能不满足了，所以要内层也加上

# Code

## ACM version

```python
import sys 


# 在nums中寻找三个不同位置的数字使得 nums[i]+nums[j]+nums[k] == 0
# 遍历nums[i]，要求nums[j]+nums[k] == -nums[i]
# 注意：三元组不能重合，既要对nums[i]去重，也要对left和right去重

class Solution:
    def threeNums(self, nums):
        if len(nums) <= 2: # 不仅是nums为空，如果长度小于3都无法找到三数之和
            return []
        ans = []
        n = len(nums)
        nums = sorted(nums)
        
        for i in range(0, n - 2): # n的取值范围：0-n-3
            # 对nums[i]进行去重，直接跳过这整个循环
            if i > 0  and nums[i] == nums[i - 1]:
                continue 
                
            left, right = i + 1, n - 1
            
            while left < right:
                if nums[left] + nums[right] < -nums[i]:
                    left += 1
                elif nums[left] + nums[right] > -nums[i]:
                    right -= 1
                else:
                    ans.append([nums[i], nums[left], nums[right]])
                    # 注意还要循环下一组：同一个nums[i]也有多种可能
                    left += 1
                    right -= 1
                    # 对left和right去重
                    while left < right and nums[left] == nums[left - 1]:
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1
        return ans


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    nums = list(map(int, data[idx].split())); idx += 1
    ans = Solution().threeNums(nums)
    print(len(ans))
    for ls in ans:
        print(' '.join(str(element) for element in ls))


# 四数之和：嵌套threeSum
```
