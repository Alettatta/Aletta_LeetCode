# Problem Description
给你一个整数数组 nums，请你找出所有满足 i != j、i != k 且 j != k，同时 nums[i] + nums[j] + nums[k] == 0 的不同三元组 [nums[i], nums[j], nums[k]]。

为保证答案唯一，输出需满足以下约束：

每个三元组内部的元素必须按照非递减顺序排列，即 [a, b, c] 满足 a <= b <= c。

所有三元组之间按字典序升序排列：先比较第一个元素，若相同再比较第二个元素，若仍相同再比较第三个元素。

答案中不能包含重复的三元组。

数据范围：

3 <= nums.length <= 3000

-10^5 <= nums[i] <= 10^5

# Solution
不要忘了去重！！！内层外层都是！！！

# Code

## LC version

```python
# 返回原始值而不是索引，使用双指针可以解决，但是第三个值必须遍历
# [-1,0,1,2,-1,-4]->[-4,-1,-1,0,1,2], sum = 0

class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        ans = []
        for i in range(len(nums)):
            # 加上nums[i]的去重
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            left = i + 1
            right = len(nums) - 1
            target = - nums[i]
            while left < right:
                if nums[left] + nums[right] < target:
                    left += 1
                elif nums[left] + nums[right] > target:
                    right -= 1
                else:
                    ans.append([nums[i], nums[left], nums[right]])
                    # 跳过重复三元组（内层双指针去重）
                    l, r = nums[left], nums[right]
                    while left < right and nums[left] == l:
                        left += 1
                    while left < right and nums[right] == r:
                        right -= 1
        return ans

# 四数之和：嵌套threeSum
```


# Complexity Analysis
- 时间复杂度：O(n^2)
- 空间复杂度：O(n)
