# Problem Description
整数数组的一个 排列 就是将其所有成员以序列或线性顺序排列。

整数数组的 下一个排列 是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典序从小到大排列在一个容器中，那么数组的 下一个排列 就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列（即，其元素按升序排列）。

例如，arr = [1, 2, 3] 的下一个排列是 [1, 3, 2]；类似地，arr = [2, 3, 1] 的下一个排列是 [3, 1, 2]；而 arr = [3, 2, 1] 的下一个排列是 [1, 2, 3]，因为 [3, 2, 1] 不存在一个字典序更大的排列。

给你一个整数数组 nums，找出 nums 的下一个排列。

必须 原地修改，只允许使用额外常数空间。

# 第三轮：卡在思路
注意都要从右往左找，因为需要改变的是后面这段

```python
# [1,3,5,4,2] -> [1,4,2,3,5]
# 下一个排列在于找到nums中降序将要开始的位置nums[i] < nums[i + 1]，也就是3——要从右往左找
# 然后从它后面找第一个比它大的位置，也就是4，交换一下，[1,4,5,3,2]——要从右往左找
# 后面这段反转：i+1到n-1

class Solution:
    def nextPermutation(self, nums):
        if not nums:
            return []
        n = len(nums)
            
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1 # 获得3的位置
            
        if i >= 0:
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i] # 交换3和4
        
        left, right = i + 1, n - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left] # 后面这段反转
            left += 1
            right -= 1

        return nums
```

# Code

## ACM version


```python
import sys 


# 以[1,2,3,6,5,4]为例，下一个排列时[1,2,4,3,5,6] -> 因为从右往左看，6→5→4 是降序，直到 3 < 6 出现"上升"
# 1. 从右往左找第一个下降点i：nums[i] < nums[i+1]；如果找到说明要改变nums[i]，找不到的话说明数组是整个降序，反转成为升序即可
# 2. 从右往左找第一个比 nums[i] 大的数 j
# 3. 交换 nums[i] 和 nums[j]
# 4. 反转 i+1 到末尾

class Solution:
    def nextPermutation(self, nums):
        n = len(nums)

        # step1: 从右往左找第一个下降点 i
        i = n - 2 # 因为比较nums[i]和nums[i+1]，i+1最大=n-1
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1

        if i >= 0:
            # step2: 从右向左找第一个比nums[i]大的数字nums[j]
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            # step3: 交换nums[i]和nums[j]
            nums[i], nums[j] = nums[j], nums[i]

        # step4: 反转i+1到末尾（上面else情况如果i<0就反转整个数组）
        left, right = i + 1, n - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1

        return nums


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    nums = list(map(int, data[idx].split())); idx += 1
    ans = Solution().nextPermutation(nums)
    print(' '.join(str(x) for x in ans))
```
