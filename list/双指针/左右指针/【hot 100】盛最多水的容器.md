# Problem Description
给你一个长度为 n 的非负整数数组 height。在坐标系中画出 n 条垂直线，第 i 条线的两个端点分别为 (i, 0) 和 (i, height[i])。

找出其中两条线，使它们与 x 轴共同构成一个容器，使该容器能装最多的水，返回容器可以储存的最大水量。

说明：你不能倾斜容器。

# 任意两根柱子存储的水量=min(柱子1, 柱子2)*x值之差，平移的话平移矮的一端

import sys

class Solution:
    def maxArea(self, height):
        n = len(height)
        left, right = 0, n - 1
        ans = 0
        while left < right: # 终止条件是left==right，水量=0
            vol = min(height[left], height[right]) * (right - left)
            ans = max(vol, ans)
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return ans
        
data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    height = list(map(int, data[idx].split())); idx += 1
    result = Solution().maxBottle(height)
    print(result)
