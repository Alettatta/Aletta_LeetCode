# Problem Description
这里有 n 个航班，它们分别从 1 到 n 进行编号。

有一份航班预订表 bookings ，表中第 i 条预订记录 bookings[i] = [firsti, lasti, seatsi] 意味着在从 firsti 到 lasti （包含 firsti 和 lasti ）的 每个航班 上预订了 seatsi 个座位。

请你返回一个长度为 n 的数组 answer，里面的元素是每个航班预定的座位总数。


# Code

## LC version

```python
# bookings = [[first, last, seats],……]，对ans[first-1]+seats，求原数组answer
# PS: 题目给了n; 1 ≤ first, last ≤ n
# 差分数组：diff[i] = nums[i] - nums[i - 1]

class Solution:
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:
        # 构造差分数组
        diff = [0] * (n + 1) # last最大是n，如果下标最大为n-1就out of index
        for op in bookings:
            first, last, seats = op[0], op[1], op[2]
            diff[first - 1] += seats
            diff[last] -= seats # last刚好是last - 1的下一位

        # 构造结果数组
        ans = [0] * n
        ans[0] = diff[0]
        for i in range(1, n): # 注意要写ans[0]的情况以及range范围
            ans[i] = ans[i - 1] + diff[i]

        return ans
```

# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
