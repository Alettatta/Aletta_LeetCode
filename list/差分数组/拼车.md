# Problem Description
车上最初有 capacity 个空座位。车 只能 向一个方向行驶（也就是说，不允许掉头或改变方向）

给定整数 capacity 和一个数组 trips ,  trips[i] = [numPassengersi, fromi, toi] 表示第 i 次旅行有 numPassengersi 乘客，接他们和放他们的位置分别是 fromi 和 toi 。这些位置是从汽车的初始位置向东的公里数。

乘客在接上新乘客之前会被放下。在路线的每个点，车内乘客总数不得超过 capacity。

当且仅当你可以在所有给定的行程中接送所有乘客时，返回 true，否则请返回 false。


# Solution


# Code

## LC version

```python
# trips[i] = op = [numPassengers, from, to]，diff[from] += numPassengers，diff[to] -= numPassengers
# 约束条件：ans[i] <= capacity 就是 True
# 问题：ans和diff的长度n？

class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        n = max(to for _, _, to in trips) + 1   # 最大站点 + 1

        # 构造差分数组
        diff = [0] * (n + 1)
        for op in trips:
            numPassengers, frm, to = op[0], op[1], op[2]
            diff[frm] += numPassengers
            diff[to] -= numPassengers

        # 构造结果数组
        ans = [0] * n
        ans[0] = diff[0]
        if ans[0] > capacity: # 注意判断是不是一开始就超载
            return False
        for i in range(1, n):
            ans[i] = ans[i - 1] + diff[i]
            if ans [i] > capacity:
                return False
        return True
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
