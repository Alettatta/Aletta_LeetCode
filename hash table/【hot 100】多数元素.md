# Problem Description
给定一个大小为 n 的数组 nums，返回其中的 多数元素。多数元素是指在数组中出现次数 大于 ⌊n/2⌋ 的元素。

题目数据保证数组中的多数元素一定存在。




# Solution
正负电子法：如果没有众数，那么这堆电子一定电中性（count=0），众数来了就+1，反之-1，最后count肯定是正，此时指针一定指众数

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        # 本质就是在nums中找一个众数
        target = 0 # 目标数字
        count = 0 # 计数器（类比一群带电粒子：数量相等的初始状态就呈电中性）
        for i in range(len(nums)):
            if count == 0:
                target = nums[i] # 当计数器为 0 时，假设 nums[i] 就是众数
                count = 1
            elif nums[i] == target:
                count += 1 # 如果是target的话，类似正电子
            else:
                count -= 1 # 反之带负电
        return target # 因为存在众数，count必然>0，此时target就是众数
```

更简单的是使用hashmap解决，**注意count = {}和count = defaultdict(int)的区别**——

普通字典 {} 在访问不存在的 key 时会直接报错；defaultdict(int) 会在访问不存在的 key 时，自动调用 int() 生成一个默认值 0

# Code

## LC version

```python
class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        n = len(nums)
        count = defaultdict(int) # 用hash存放num出现的次数，返回count>n//2的
        for num in nums:
            count[num] += 1
            if count[num] > n // 2:
                return num
```

# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)，如果用哈希表dict的话空间复杂度是O(n)
