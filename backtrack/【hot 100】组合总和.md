# Problem Description
给你一个 无重复元素 的整数数组 candidates 和一个目标整数 target，找出 candidates 中可以使数字和为目标数 target 的所有 不同组合，并以列表形式返回。你可以按 任意顺序 返回这些组合。

candidates 中的 同一个 数字可以 无限制重复被选取。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 target 的不同组合数少于 150 个。



# Code

## ACM version

```python
import sys 


# 无重复元素、可以复用
class Solution:
    def combinationSum(self, candidates, target):
        ans = []
        path = []

        def backtrack(start, remain): # 传参还要remain，表示距离target还要多少
            # base case
            if remain == 0:
                ans.append(path[:])
                return 
                
            # 剪枝
            if remain < 0:
                return 

            for i in range(start, len(candidates)):
                path.append(candidates[i])
                backtrack(i, remain - candidates[i]) # 体现可以复用，还是从i开始，但是总和变化了
                path.pop()
                
        backtrack(0, target)
        return ans


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n, target = map(int, data[idx].split()); idx += 1
    candidates = list(map(int, data[idx].split())); idx += 1
    ans = Solution().combinationSum(candidates, target)
    for ls in ans:
        print(' '.join(str(x) for x in ls))
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
