# Problem Description
给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是 回文串。返回 s 所有可能的分割方案。


# Solution
子集/组合问题，同时保证子集是回文串，有重复元素、不可复用，注意base case是分割完字符串（遍历到回溯树的底端）、还要注意怎么判断回文串（双指针更快，因为是O(1)，如果用sort的话是O(nlogn)）

# Code

## LC version

```python
class Solution:
    def __init__(self):
        self.ans = []
        self.track = []

        
    def partition(self, s: str) -> List[List[str]]:
        if not s:
            return self.ans 
        self.backtrack(s, 0)
        return self.ans

    
    def backtrack(self, s, start):
        # base case：整个 s 被成功分割为若干个回文子串，记下答案
        if start == len(s):
            self.ans.append(self.track.copy())

        for i in range(start, len(s)):
            # 如果不是回文串，不能分割
            if not self.isPalindrome(s, start, i):
                continue
            # 选择
            self.track.append(s[start: i+1])
            # 回溯
            self.backtrack(s, i + 1)
            # 撤销选择
            self.track.pop()

            
    # 用双指针判断是否是回文串
    def isPalindrome(self, s, left, right):
        while left < right:
            if s[left] != s[right]:
                return False
            left += 1
            right -= 1
        return True
```

## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List


class Solution:
    def __init__(self):
        self.ans = []
        self.track = []

        
    def partition(self, s: str) -> List[List[str]]:
        if not s:
            return self.ans 
        self.backtrack(s, 0)
        return self.ans

    
    def backtrack(self, s, start):
        # base case：整个 s 被成功分割为若干个回文子串，记下答案
        if start == len(s):
            self.ans.append(self.track.copy())

        for i in range(start, len(s)):
            # 如果不是回文串，不能分割
            if not self.isPalindrome(s, start, i):
                continue
            # 选择
            self.track.append(s[start: i+1])
            # 回溯
            self.backtrack(s, i + 1)
            # 撤销选择
            self.track.pop()

            
    # 用双指针判断是否是回文串
    def isPalindrome(self, s, left, right):
        while left < right:
            if s[left] != s[right]:
                return False
            left += 1
            right -= 1
        return True


for line in sys.stdin:
    s = line.strip()
    result = Solution().partition(s)
    result.sort()
    print(len(result))
    for scheme in result:
        print(" ".join(scheme))
```
