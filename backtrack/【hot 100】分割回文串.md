# Problem Description
给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是 回文串。返回 s 所有可能的分割方案。

# Solution

本题两个问题：第一，回文串如何判断reverse()/[::-1]/左右指针

第二，start和i的位置关系：每一轮start固定，i向右、决定s[start:i+1]切多少

以'aab'为例，i=0的时候：

```python
索引:   0    1    2
字符:   a    a    b
        ↑
      start
        ↑
        i
子串 s[0:1] = "a"     （start 到 i，含 i）
```

i=1:
```python
索引:   0    1    2
字符:   a    a    b
        ↑    ↑
      start  i
子串 s[0:2] = "aa"    （start 到 i，含 i）
```

i=2:
```python
索引:   0    1    2
字符:   a    a    b
        ↑         ↑
      start       i
子串 s[0:3] = "aab"   （不是回文，剪掉）
``

然后回溯backtrack(i+1)，其实start就+1


# Code

## ACM version

```python
import sys


# 有重复元素不可以复用，子集问题
class Solution:
    def partition(self, s):
        if not s:
            return []

        ans = []
        path = []

        def is_palindrome(sub):
            return sub == sub[::-1]

        def backtrack(start): # start：上一刀切完后的位置（包含）；i：当前这一刀要切到哪（包含）
            # base case：因为要把s切割；切到字符串末尾，说明完成一种分割方案
            if start == len(s):
                ans.append(path[:])
                return 
                
            for i in range(start, len(s)):
                sub = s[start:i + 1] # 切一刀使得子串为下标 start 到 i（含 i）的字符
                if not is_palindrome(sub):
                    continue
                path.append(sub)
                backtrack(i + 1)
                path.pop()

        backtrack(0)
        return ans


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    s = data[idx]; idx += 1
    ans = Solution().partition(s)
    print(len(ans))
    for ls in ans:
        print(' '.join(ls))
```
