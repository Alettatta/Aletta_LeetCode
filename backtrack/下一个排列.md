https://labuladong.online/zh/problem/leetcode/next-permutation/description/


# Problem Description
整数数组的一个 排列 就是将其所有成员以序列或线性顺序排列。

整数数组的 下一个排列 是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典序从小到大排列在一个容器中，那么数组的 下一个排列 就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列（即，其元素按升序排列）。

例如，arr = [1, 2, 3] 的下一个排列是 [1, 3, 2]；类似地，arr = [2, 3, 1] 的下一个排列是 [3, 1, 2]；而 arr = [3, 2, 1] 的下一个排列是 [1, 2, 3]，因为 [3, 2, 1] 不存在一个字典序更大的排列。

给你一个整数数组 nums，找出 nums 的下一个排列。

必须 原地修改，只允许使用额外常数空间。


# Solution
不同于暴力枚举所有排列（传统排列问题）

我们需要从字典序的定义里找规律。字典序（Lexicographical Order），就是按照查字典时单词排列的顺序进行比较。从左到右，一个字符一个字符比较，第一个不同的字符决定大小。

字典序比较是从左到右逐位进行的，所以要让排列「刚好大一点」，改动应该尽量靠右、幅度尽量小，越靠左的位置越要保持不变。从右边的哪里开始改呢？

如果一段后缀本身已经是非递增的（从左到右不上升），那它就是这些元素能拼出的最大排列了，单独动这段后缀只会变小。所以破局点就是从右往左扫到的第一个「升序位置」i，即满足 nums[i] < nums[i+1] 的位置。找到 i 之后，nums[i+1..] 一定是非递增的。

接下来，要把 nums[i] 换成后缀中比它大的最小元素。因为后缀非递增，从右往左扫到的第一个大于 nums[i] 的元素 nums[j] 就是目标。交换 nums[i] 和 nums[j] 后，后缀仍然保持非递增（把一个较大的数换出去、一个不更大的数换进来，不会破坏单调性）。

此时后缀是这一档排列里最大的后缀，把它反转就变成最小的后缀，整体就是「下一个排列」。

如果一开始就找不到升序位置 i，说明整个数组已经是最大排列，按题意直接反转整个数组变成升序即可，刚好和反转后缀的操作统一。

拿 [1, 1, 5, 1] 走一遍：从右往左扫，i = 1（nums[1] = 1 < nums[2] = 5）；后缀 [5, 1] 中从右往左找到第一个大于 1 的是 nums[2] = 5，交换得到 [1, 5, 1, 1]；反转后缀 [1, 1] 还是 [1, 1]，最终结果 [1, 5, 1, 1]。


# Code

## LC version

以一个例子展示：

假设数组是 1 2 7 4 3 1（答案应该是 1 3 1 2 4 7）

算法第一步，从右往左找第一个满足 nums[i] < nums[i+1] 的位置。2<7，所以 nums[i] = 2。可以发现：i 后面的这一段一定是降序排列（7 4 3 1，因为如果不是降序，算法早就停下来了）。

然后找到比 2 大一点的数字，是 3，交换 2 和 3，得到 1 3 7 4 2 1，但是后缀依然是降序、太大了。

所以最后把后缀倒过来，得到 1 3 1 2 4 7，这才是真正的刚刚比原数组大一点点

```python
class Solution:
    def nextPermutation(self, nums: List[int]) -> List[int]:
        n = len(nums)
        
        # 从右往左找第一个升序位置i，满足nums[i]<nums[i+1]
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1 # 找到了升序位置前面一个数字
            
        if i >= 0:
            # 从右往左找第一个大于 nums[i] 的元素 nums[j]，交换二者
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i]

        # 处理后缀：把后缀从降序变成升序，让整个数组变成"刚好比原来大一点"的排列。
        # 把后缀从降序变成升序，让整个数组变成"刚好比原来大一点"的排列。
        left, right = i + 1, n - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
            
        return nums
```


## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List


class Solution:
    def nextPermutation(self, nums: List[int]) -> List[int]:
        n = len(nums)
        
        # 从右往左找第一个升序位置i，满足nums[i]<nums[i+1]
        i = n - 2
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1 # 找到了升序位置前面一个数字
            
        if i >= 0:
            # 从右往左找第一个大于 nums[i] 的元素 nums[j]，交换二者
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i]

        # 处理后缀：把后缀从降序变成升序，让整个数组变成"刚好比原来大一点"的排列。
        # 把后缀从降序变成升序，让整个数组变成"刚好比原来大一点"的排列。
        left, right = i + 1, n - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
            
        return nums
        

pending_n = None
for line in sys.stdin:
    line = line.strip()
    if not line:
        continue
    if pending_n is None:
        pending_n = int(line)
        continue
    nums = list(map(int, line.split()))
    result = Solution().nextPermutation(nums)
    print(' '.join(str(x) for x in result))
    pending_n = None
```
