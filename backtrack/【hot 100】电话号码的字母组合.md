# Problem Description
给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。答案可以按 任意顺序 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。


# Solution
建立哈希表映射数字和字符：不用建立字典，因为是2-9，可以建立index-value，用list格式即可

输入的digits是定好顺序的，本质是元素无重复、不可复用的组合/子集问题（不是排序！因为顺序不可以颠倒）

先取数字->对应hashmap规则得到字符->字符的组合


# Code

## ACM version


```python
import sys 

class Solution:
    def letterCombinations(self, digits):
        # 特殊情况
        if not digits:
            return []

        hashmap = [
            "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
        ] # 不用写key，用list的索引下标对应即可
        
        ans = []
        path = []
        k = len(digits)

        # backtrack函数的作用：backtrack(状态) = 在当前这个状态下，把从它出发的所有可能结果都收集完
        # 对于这道题而言，需要的状态就是digits的每个元素数字
        def backtrack(idx): 
            # base case
            if len(path) == k:
                ans.append(''.join(path))
                return

            digit = int(digits[idx]) # 索引idx -> 数字digit
            for ch in hashmap[digit]: # 遍历这个数字对应的所有字母
                path.append(ch)
                backtrack(idx + 1) # 处理下一个数字
                path.pop()

        backtrack(0)
        return ans

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    digits = data[idx]; idx += 1
    ans = Solution().letterCombinations(digits)
    print(len(ans))
    for ch in ans:
        print(ch)
```
