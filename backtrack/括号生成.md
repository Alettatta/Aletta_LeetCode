# Problem Description
数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且有效的括号组合。

为了保证答案唯一，请将所有合法的括号组合按字典序升序排列后输出。



# Solution
n的个数表示有n个左/右括号，本质是组合/子集问题、有重复元素、不可复用；为了节约效率，剪枝需要考虑这个括号语法成立吗——怎么判断组合是否合法：

**对于一个「合法」的括号字符串组合 p，必然对于任何 0 <= i < len(p) 都有：子串 p[0..i] 中左括号的数量都大于或等于右括号的数量。**

注意这道题不用start遍历，因为本身给的就不是一个可迭代对象，使用left和right两个参数即可


# Code

## LC version

```python
class Solution:
    def __init__(self):
        self.ans = []
        self.track = ''
        
    def generateParenthesis(self, n: int) -> List[str]:
        if n == 0:
            return self.ans
        self.backtrack(n, n) # 可用的左括号和右括号数量初始化为 n
        return self.ans

    # 可用的左括号数量为 left 个，可用的右括号数量为 right 个
    def backtrack(self, left, right):
        # 判断是否合法
        if right < left:
            return
        if left < 0 or right < 0:
            return
        # base case
        if left == 0  and right == 0:
            self.ans.append(self.track)
            return

        # 做选择，尝试放一个左括号
        self.track += "("
        self.backtrack(left - 1, right)
        # 撤消选择
        self.track = self.track[:-1] # track是字符串没有pop，这么切片去掉最后一个值

        # 做选择，尝试放一个右括号
        self.track += ")"
        self.backtrack(left, right - 1)
        # 撤消选择
        self.track = self.track[:-1] # track是字符串没有pop，这么切片去掉最后一个值
```

注意：track是字符串，没有copy()方法，因为列表是可变对象，同一个列表对象会不断被修改，所以保存答案时要复制


## ACM version

**ACM 模式的注意点：**

- 需要 import 完整的类（包括 sys、typing 等）
- 数据在标准输入流 stdin 中，全部是原始的文本字符串
- 必须用 print() 手动将结果写到标准输出流 stdout
- 需要写 while 或 for line in sys.stdin 循环处理，直到文件结束（EOF）

```python
import sys
from typing import List


class Solution:
    def __init__(self):
        self.ans = []
        self.track = ''
        
    def generateParenthesis(self, n: int) -> List[str]:

            return self.ans
        self.backtrack(n, n) # 可用的左括号和右括号数量初始化为 n
        return self.ans

    # 可用的左括号数量为 left 个，可用的右括号数量为 right 个
    def backtrack(self, left, right):
        # 判断是否合法
        if right < left:
            return
        if left < 0 or right < 0:
            return
        # base case
        if left == 0  and right == 0:
            self.ans.append(self.track)
            return

        # 做选择，尝试放一个左括号
        self.track += "("
        self.backtrack(left - 1, right)
        # 撤消选择
        self.track = self.track[:-1] # track是字符串没有pop，这么切片去掉最后一个值

        # 撤消选择
        self.track = self.track[:-1] # track是字符串没有pop，这么切片去掉最后一个值


for line in sys.stdin:
    n = int(line.strip())
    result = Solution().generateParenthesis(n)
    result.sort()
    print(len(result))
    for s in result:
        print(s)
```
