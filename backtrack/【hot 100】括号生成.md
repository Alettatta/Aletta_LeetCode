# Problem Description
数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且有效的括号组合。

为了保证答案唯一，请将所有合法的括号组合按字典序升序排列后输出。



# Solution

有重复元素，不可以复用，生成之后需要判断括号组合是否有效；暴力枚举之后判断合法时间复杂度高，所以其实有些位置放左右括号本身可以判断是否合法；

- basecase：左右括号各n个；
- 左括号(什么时候可以放：已用左括号数 < n；
- 右括号)什么时候可以放：左括号个数大于右括号


# Code

## ACM version

```python
import sys 


# 有重复元素，不可以复用，生成之后需要判断括号组合是否有效
# 暴力枚举之后判断合法时间复杂度高，所以其实有些位置放左右括号本身可以判断是否合法；
# basecase：左右括号各n个；(什么时候可以放：已用左括号数 < n；)什么时候可以放：左括号个数大于右括号

class Solution:
    def generateParenthesis(self, n):
        ans = []
        path = []

        def backtrack(left, right): # 传入参数是左右括号个数
            if len(path) == 2 * n:
                ans.append(''.join(path))
                return 

            # 放左括号
            if left < n:
                path.append('(')
                backtrack(left + 1, right)
                path.pop()

            # 放右括号
            if left > right:
                path.append(')')
                backtrack(left, right + 1)
                path.pop()
                
        backtrack(0, 0)
        return ans


data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    ans = Solution().generateParenthesis(n)
    print(len(ans))
    for s in ans:
        print(s)
```




# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
