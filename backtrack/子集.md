# Problem Description
给你一个整数数组 nums，数组中的元素 互不相同。返回该数组所有可能的子集（幂集）。

解集 不能 包含重复的子集。你可以按 任意顺序 返回解集。



# Solution
其实过程belike：

```python
                        []  (根, start=0)
        ┌───────────────┼───────────────┐
       [1]             [2]             [3]      ← 第一层: 选第一个元素
      start=1         start=2         start=3
    ┌───┴───┐          │
  [1,2]   [1,3]      [2,3]                     ← 第二层
 start=2 start=3    start=3
   │
 [1,2,3]                                        ← 第三层
```

用path收集每条路径遍历之后的答案——遍历依靠backtrack(start)寻找nums[start……]的子集、不断下探孩子节点，如果没有孩子就pop（整个过程类似DFS）

| 动作 | path | 说明 |
|------|------|------|
| `backtrack(0)` | `[]` | 根节点，先 `res += []` |
| `i=0, append(1)` | `[1]` | 走边 1，进入 `[1]` |
| `backtrack(1)` | `[1]` | 节点 `[1]`，`res += [1]` |
| `i=1, append(2)` | `[1,2]` | 走边 2，进入 `[1,2]` |
| `backtrack(2)` | `[1,2]` | 节点 `[1,2]`，`res += [1,2]` |
| `i=2, append(3)` | `[1,2,3]` | 进入 `[1,2,3]`，`res += [1,2,3]` |
| `backtrack(3)` | `[1,2,3]` | 无孩子，返回 |
| `pop` | `[1,2]` | 退回 `[1,2]` |
| `pop` | `[1]` | 退回 `[1]` |
| `i=2, append(3)` | `[1,3]` | 换兄弟，进入 `[1,3]`，`res += [1,3]` |

# Code

## ACM version

```python
import sys 

class Solution:
    def subsets(self, nums):
        ans = []
        path = [] # 记录每一个子集（每一条回溯路径）

        def backtrack(start): # 决定路径的开始索引，需要找nums[start……]的子集
            ans.append(path[:]) # 空集也是子集
            for i in range(start, len(nums)):
                path.append(nums[i])
                backtrack(i + 1)
                path.pop()
            
        backtrack(0)
        return ans

data = sys.stdin.read().strip().split('\n')
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1
    nums = list(map(int, data[idx].split())); idx += 1
    ans = Solution().subsets(nums)
    for ls in ans:
        if ls == []:
            print('-')
        else:
            print(' '.join(str(x) for x in ls))
```


# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
