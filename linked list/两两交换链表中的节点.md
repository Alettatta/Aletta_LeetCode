# Problem Description
给你一个链表的头节点 head，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。






# Code

## LC version

```python
class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # base case
        if head is None or head.next is None:
            return head

        # 翻转前面2个
        slow = head
        fast = head.next
        others = head.next.next
        fast.next = slow

        # 递归翻转剩下的
        slow.next = self.swapPairs(others)
        return fast
```



# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
