# Problem Description
给你一个单链表的头节点 head，请你判断该链表是否为回文链表。如果是，返回 true；否则，返回 false。

回文序列是指正序（从左向右）和倒序（从右向左）读都相同的序列。

数据范围：

链表中节点的数目范围是 [1, 100000]

0 <= Node.val <= 9

给你一个单链表的头节点 head，请你判断该链表是否为回文链表。


# Key Points
寻找回文串从中间向外端扩展

```python
# 在 s 中寻找以 s[left] 和 s[right] 为中心的最长回文串
def palindrome(s: str, left: int, right: int) -> str:
    # 防止索引越界
    while left >= 0 and right < len(s) and s[left] == s[right]:
        # 双指针，向两边展开
        left -= 1
        right += 1
    # 返回以 s[left] 和 s[right] 为中心的最长回文串
    return s[(left + 1):right]
```

判断回文串用reverse即可


# Code

## LC version

```python
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        # 判断回文串的要点是str = reverse(str)；前半段和reverse(后半段)完全一样
        # 所以需要先找到中点，使用快慢指针
        fast, slow = head, head
        while fast and fast.next: # 退出循环的时候slow在中点
            fast = fast.next.next
            slow = slow.next
        second = self.reverse(slow)

        p1, p2 = head, second
        while p2:
            if p1.val != p2.val:
                return False
            p1 = p1.next
            p2 = p2.next
        return True
               
    def reverse(self, head: Optional[ListNode]) -> Optional[ListNode]:
        pre = None
        while head:
            nxt = head.next # 需要先保存原来head的下一个，现在变成上一个
            head.next = pre # 关键就是这步
            pre = head
            head = nxt
        return pre
```
