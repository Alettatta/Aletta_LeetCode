# Problem Description
给你单链表的头节点 head，请将其按 升序 排列并返回 排序后的链表。

数据范围：

链表中节点的数目范围是 [0, 5 * 10^4]

-10^5 <= Node.val <= 10^5

给你单链表的头节点 head，请将其按 升序 排列并返回 排序后的链表。


# Key Points
用递归思想，把链表从中间一分为二，分别排好左右两半，然后合成有序链表

把链表从中间一分为二，使用slow（一次一步）和fast（一次两步），这样fast到最后一个时候哦，slow在中点

slow从head开始，fast从head.next开始，不然只有2个节点的时候，无法递归下去，死循环


# Code

## LC version

```python
# 最好的排序方法是归并排序，假设我把一个值拎出来、排好剩下的，问题在于这个值插在哪里、左右可能都有值
# 所以可以把序列从中间一分为二（左半段：head 到中点；右半段：中点后一个到末尾），递归排好左右两半，最后合并两个有序子序列。

class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 特殊情况：链表为空或者只有一个节点，本身就有序
        if head is None or head.next is None:
            return head

        # 找到链表中点，比如12345
        slow, fast = head, head.next
        while fast and fast.next: # 必须加上fast.next，假设只有fast，那么fast到了最后一个值还不停，还要往前一步，此时slow对应的位置是mid+1
            slow = slow.next
            fast = fast.next.next
        mid = slow.next # 右半段的头是mid+1
        slow.next = None     # 关键：断开，左半段到 slow 结束

        # 左右分别排序
        left = self.sortList(head)
        right = self.sortList(mid)

        # 合并left和right
        return self.mergeTwoLists(left, right)

    
    # 合并2个有序链表
    def mergeTwoLists(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(-1)
        p = dummy
        while l1 is not None and l2 is not None:
            if l1.val <= l2.val:
                p.next = l1
                l1 = l1.next
            else:
                p.next = l2
                l2 = l2.next
            p = p.next
        p.next = l1 if l1 is not None else l2 # 处理剩余部分
        return dummy.next
```

PS：为什么下面这种写法不对，如果n为偶数，slow停在重点右侧（比如1234，slow停在3）
```python
slow, fast = head, head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
mid = slow
slow.next = None   # ❌ 这样写不对
```

# Complexity Analysis
- 时间复杂度：O(nlogn)，递归把链表对半分，递归树高度为 O(logn)；每一层所有合并操作的总代价是 O(n)，所以总复杂度是 O(nlogn)。
- 空间复杂度：O(logn)，递归调用栈的深度
