# Problem Description
给你一个链表的头节点 head，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

# Code

## LC version

```python
# 交换前2个节点，从第三个节点开始递归调用，然后拼起来
class Solution:
    def swapPairs(self, head: ListNode | None) -> ListNode | None:
        # 如果个数都不够2个
        p = head
        for _ in range(2):
            if p is None:
                return head
            p = p.next
        third = p # 满足条件的话出来的就是第三个节点

        second = head.next # 注意保存第二个节点，因为这个节点最后是头结点要返回
        second.next = head
        head.next = self.swapPairs(third)
        return second
```



# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(1)
