# Problem
https://leetcode.cn/problems/partition-list/description/


# Problem Description
给你一个链表的头节点 head 和一个特定值 x ，请你对链表进行分隔，使得所有 小于 x 的节点都出现在 大于或等于 x 的节点之前。

你应当 保留 两个分区中每个节点的初始相对位置。



# Solution
把<x和>=x的部分分开，再连接上

如果我们需要把原链表的节点接到新链表上，而不是 new 新节点来组成新链表的话，那么断开节点和原链表之间的链接可能是必要的。那其实我们可以养成一个好习惯，但凡遇到这种情况，就把原链表的节点断开，这样就不会出错了。

# Code

## LC version

```python
class Solution:
    def partition(self, head: ListNode | None, x: int) -> ListNode | None:
        # 需要2个头结点，一个存放<x的节点，一个存放>=x的节点
        dummy1, dummy2 = ListNode(-1), ListNode(-1)
        p = head
        p1, p2 = dummy1, dummy2

        while p is not None:
            if p.val >= x:
                p2.next = p
                p2 = p2.next
            else:
                p1.next = p
                p1 = p1.next

            # 不能直接p = p.next，不然可能出现环
            temp = p.next
            p.next = None # 断开和后面链表的链接，防止成环
            p = temp

        p1.next = dummy2.next # 小的在前面
        return dummy1.next
```

# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
