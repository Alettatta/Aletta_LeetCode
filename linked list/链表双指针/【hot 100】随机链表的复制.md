# Problem Description
给你一个长度为 n 的链表，每个节点包含一个额外增加的随机指针 random，该指针可以指向链表中的任何节点或空节点。

请你构造这个链表的深拷贝。深拷贝应当由 n 个全新节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 next 指针和 random 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。复制链表中的指针都不应指向原链表中的节点。

例如，如果原链表中有 X 和 Y 两个节点，其中 X.random --> Y。那么在复制链表中对应的两个节点 x 和 y，同样有 x.random --> y。

返回复制链表的头节点。



# Solution

理解题意：

1. 什么是"带随机指针的链表"

   普通链表节点belike：
   ```python
   class Node:
    def __init__(self, val):
        self.val = val
        self.next = None   # 指向下一个节点
   ```
   
   带random指针的链表节点belike：random指向任一节点
   ```python
   class Node:
       def __init__(self, val):
       self.val = val
       self.next = None     # 指向下一个节点
       self.random = None   # 指向链表中任意一个节点，或 None
   ```
   
2. "深拷贝"

   深拷贝 = 造一份完全独立的副本：新链表有 n 个全新节点（不是原来那些节点）；新节点的 val 和原节点一样；新节点的 next 和 random 指向的也是新链表里的新节点，而不是原链表的节点

3. 本题和普通链表的深拷贝的区别

   普通链表的深拷贝很简单：遍历一遍，边读边建新节点，接上 next 就行。

   但 random 有麻烦：当你创建节点 1 的副本 1' 时，1.random 指向 3，可节点 3 的副本 3' 还没创建呢！

   你可能想"先建完所有节点，再连 random"。那问题又来了：建完 1'、2'、3' 之后，1'.random 应该指向 3'，可你怎么根据"原来指向 3"找到"3'是哪个"？所以需要一个映射表：映射原节点到新节点的关系

# Code

## LC version

```python
class Solution:
    def copyRandomList(self, head):
        if head is None:
            return None

        # 先为所有原始节点建立新结点的映射
        old_to_new = {} # {1: 1'}
        cur = head
        while cur:
            old_to_new[cur] = ListNode(cur.val) # 深拷贝原始节点
            cur = cur.next

        # 接好next和random
        cur = head
        while cur:
            new_node = old_to_new[cur] # 新结点
            new_node.next = old_to_new.get(cur.next) # 1'也要指向原来1的next
            new_node.random = old_to_new.get(cur.random) # 1'也要指向原来1的random
            cur = cur.next

        return head
```
## ACM version

```python
import sys 

class ListNode:
    def __init__(self, val = 0, next = None, random = None):
        self.val = val
        self.next = next
        self.random = random

class Solution:
    def copyRandomList(self, head):
        if head is None:
            return None

        # 先为所有原始节点建立新结点的映射
        old_to_new = {} # {1: 1'}
        cur = head
        while cur:
            old_to_new[cur] = ListNode(cur.val) # 深拷贝原始节点
            cur = cur.next

        # 接好next和random
        cur = head
        while cur:
            new_node = old_to_new[cur] # 新结点
            new_node.next = old_to_new.get(cur.next) # 1'也要指向原来1的next
            new_node.random = old_to_new.get(cur.random) # 1'也要指向原来1的random
            cur = cur.next

        return head

def build_list(array): # array = [(val, random_idx)……]
    dummy = ListNode(-1)
    p = dummy
    nodes = [] # 保存每个新节点的引用，供 random 按下标取
    
    # 建立next
    for (val, _) in array:
        p.next = ListNode(val)
        p = p.next
        nodes.append(p)
        
    # 建立random
    for i, (_, random_idx) in enumerate(array): # [(0, (7, -1))……]
        if random_idx != -1:
            nodes[i].random = nodes[random_idx]
            
    return dummy.next

def print_list(head):
    # 先收集所有节点，建立 节点 -> 下标 映射
    nodes = []
    p = head
    while p is not None:
        nodes.append(p)
        p = p.next

    index_of = {node: i for i, node in enumerate(nodes)}

    print(len(nodes))
    for node in nodes:
        r = index_of[node.random] if node.random else -1
        print(node.val, r)
    
data = sys.stdin.read().strip().split("\n")
idx = 0
while idx < len(data):
    n = int(data[idx]); idx += 1 # 链表节点个数
    array = []
    for _ in range(n): # '7 -1'为val和random的索引下标
        v, r = map(int, data[idx].split()); idx += 1
        array.append((v, r))
    head = build_list(array) # 建原链表
    new_head = Solution().copyRandomList(head) # 深拷贝
    print_list(new_head) # 输出新链表
```

# Complexity Analysis
- 时间复杂度：O(n)
- 空间复杂度：O(n)
